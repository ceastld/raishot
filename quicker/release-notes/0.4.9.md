# 0.4.9

- 选区增加紧凑样式条，可快速切换原样、卡片、描边，并记住圆角与阴影设置。
- 整合文字识别、翻译与表格入口，改善正文夹表格的识别、复制和译文对照。
- 改善自动选区在细小元素之间移动时反复闪回整个窗口的问题。
- 改善录屏预览的像素对齐，并完善截图与贴图之间的边框效果一致性。
- Quicker 动作增加区域截图、启动托盘、检查程序文件右键入口，修复显式截图参数被默认托盘模式覆盖的问题。
- 随包提供完整 VC++ 与 ONNX Runtime 运行库及许可证，动作启动前核验完整文件清单。

此版本为 Windows x64 便携依赖包。分发版本与程序内部版本分别记录在包内 `manifest.json`。
