# 0.4.12

- 产品更名为 RabShot，程序入口改为 `rabshot.exe`、`rabshot-gpui.exe` 和 `rabshot-cli.exe`；Quicker 动作名称为 `rabshot`。
- 迁移旧品牌数据时优先使用最近的 Kirie 目录；已有 RabShot 数据目录时继续使用，不合并或删除其它旧目录。
- 修复 Quicker 在没有同版本托盘时点击动作无响应：冷启动使用明确的条件分支，同版本托盘继续直接接收截图通知。
- 设置文件改为分领域 JSON，首次读取迁移旧 INI 并保留备份；OCR 首次下载增加进度提示，面板复制正文后关闭截图。
- OCR 依赖下载自动测速选源，失败时回退；更新“更多”菜单、分组布局与提示样式。
- 修复 HDR 屏的 DXGI 截图过曝，按系统 SDR 白点换算回 sRGB。
- 调整截图快捷键提示、贴图工具栏与圆角边框显示；贴图图片平铺保存在 `pins` 目录，迁移与清理仅处理程序自有文件。

Windows x64 依赖包已使用 CI 产物发布，包含 VC++ 与 ONNX Runtime 运行库。V1 原动作完成首下载、完整校验、托盘启动与真实截图验证；V2 账号动作已更新，客户端需同步。分发版本与程序内部版本分别记录在包内 `manifest.json`。

动作名为 `rabshot`，已[非公开分享](https://getquicker.net/Sharedaction?code=8cb3e0ee-148d-4879-51f3-08df2d739eae)。本次未进行跨账号或异机验证。
