# 0.4.14

本版在 0.4.13 基础上补充帮助与交互改进，并优化动作触发速度。

- 主界面新增“帮助与快捷键”页，按截图、贴图、长截图、录屏等用途整理操作说明；快捷键随当前设置显示，托盘帮助与截图内帮助使用同一份内容。
- 独立图片编辑窗口有未保存或未复制的修改时，第一次关闭或按 Esc 先提示，再次操作才放弃修改；窗口按图片大小居中打开，标题显示文件名。
- 清理图片编辑与贴图标注中不适用的菜单项，补充快速保存快捷键，统一“历史记录”“管理贴图”等入口文案，并将多处提示改为更易理解的说明。
- 优化工具栏下拉菜单对属性栏的避让，修正选中色块外环与色点的对齐。
- 保存规则与翻译服务有改动时才显示“取消修改／应用”，明确修改后的生效方式；恢复默认仍需点击“应用”。
- 内置翻译服务首次发送文字时说明发送内容及服务设置入口，明确只发送文字，不发送图片和剪贴板。
- 优化动作触发路径：已有托盘时直接通知，跳过依赖检查和额外程序启动；长时间闲置后的首次触发仍待持续观察。

首次使用自动下载 Windows x64 程序与运行库，OCR 模型和字典按需下载。升级前请正常退出旧版托盘，再启动新版。
