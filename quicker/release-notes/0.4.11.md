# 0.4.11

- 选区外观提供“原样、圆角、卡片、描边、窗口”五个样式，点击即可切换，悬停预览、移开恢复；空间不足时收为样式画廊入口。
- 每个样式分别记住圆角、阴影与边框设置，切换样式可恢复上次调整；修复重新截图和旧配置迁移时的样式记忆。
- 外观参数改为面板内直接调整，数值设为 0 即关闭对应效果，“恢复默认”只重置当前样式。
- 更新二级工具栏与选区外观面板布局，保留常用操作入口；预览实际样式边框时隐藏蓝色选区轮廓，控制点仍可调整选区。

此版本为 Windows x64 便携依赖包，包含 VC++ 与 ONNX Runtime 运行库。分发版本与程序内部版本分别记录在包内 `manifest.json`。
