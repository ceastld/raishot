# 0.4.17

本版新增公式识别与多套翻译服务配置，改进快捷键、工具栏和保存设置。

- 新增公式识别：选区图片可交给所配置的 API（默认 DeepSeek），预览文字、公式和表格，支持复制 LaTeX、Markdown 或排版图片。
- 文字翻译和公式识别可分别选择 Index、DeepSeek 或自定义兼容服务；文字翻译默认使用无需密钥的 Index，API Key 按当前 Windows 用户加密保存。
- 翻译保护代码、公式、网址、占位符和数值；表格保留行列结构，复制译文同时提供 TSV 和 HTML。
- 快捷键设置新增贴图、分组和应用相关操作；工具栏支持拖动排序和添加，保存页增加“打开文件夹”。
- 修复字体菜单首次打开时数秒无响应，以及批处理输出目录路径别名可能占用其它输入的问题。
- 新增独立安装包，便携包与 Quicker 动作继续提供。

升级前请从旧版托盘正常退出，再更新动作并点击启动新版。已有合格 OCR 缓存继续复用；公式识别和翻译会向所选服务发送待处理图片或文字。
