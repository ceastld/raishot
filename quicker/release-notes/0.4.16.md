# 0.4.16

本版修复部分国内网络无法下载 OCR 模型的问题，并整理图库工具入口。

- 文字识别的 Tiny、Small 模型、字典、许可证及运行库恢复镜像与官方双源，自动选择可用来源，失败后换源；下载仍校验固定大小和 SHA256。
- 修复长截图里悬浮按钮重复与接缝残片。
- 图库新增“新建”菜单，集中提供截图、录屏、剪贴板贴图、二维码与导入图片入口；支持拖入图片或 Ctrl+O。
- 图库与查看器的“编辑”会贴出图片并展开标注工具；图片工具支持在主窗口弹层打开及互相切换。

下载来源已在国内和海外节点完成完整下载与大小、摘要核验。升级前请从旧版托盘正常退出，再点击动作启动新版；已有合格 OCR 缓存继续复用。
