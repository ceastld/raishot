# 0.4.13 · 首个公开版本候选

本版包含 0.4.12 之后的最新改动，已使用 CI 产物发布私有依赖；现有 V1 动作、V2 账号动作与原非公开分享均更新到 0.4.13，保留自选图标。V1 已完成新包下载与完整校验，V2 客户端同步后生效；动作保持非公开。

- 贴图、截图历史、录屏历史与设置合并到一个主界面；贴图页提供显示器布局图、分组、显示、锁定、鼠标穿透与最近关闭恢复。
- 长截图完成后直接复制；需要裁边或删段时打开调整窗，通过总览定位长图，可撤销、重做并继续采集；采集中沿滚动方向移动选区不再暂停。
- 贴图增加可视标题、操作提示和 Shift 精细缩放；空闲时 Esc 一次关闭贴图。
- 优化文字贴图渲染与贴图缩放，修正隐藏窗口导致长图调整窗不刷新的问题。
- 截图、贴图与长截图复制时保留落点信息，再贴图沿用对应位置与显示大小。
- 录屏工具栏增加按钮说明气泡、分级消息和可展开的标注工具栏。

首次使用自动下载 Windows x64 程序与运行库，OCR 模型和字典按需下载。升级前请正常退出旧版托盘，再启动新版。
