# 0.4.15

本版更名为 RaiShot，整理图库与媒体入口，并改进录屏、长截图和输入操作。

- 程序与动作显示名称改为 RaiShot，升级时支持迁移旧版设置、贴图和 OCR 缓存。
- 主界面“历史”改为“图库”，集中管理截图、贴图和录屏；支持多选，并按所选内容提供图片、视频和批处理工具。
- 图片和视频可在主窗口内查看，关闭查看弹层后返回图库；常规图片调整继续使用编辑器与贴图。
- 分组、文档和图库索引改用 SQLite，启动后后台导入已有 JSON 数据，图片和视频保留为独立文件。
- 截图与剪贴板贴图支持更多键鼠触发组合，增加远程画面兼容设置。
- 录屏加入点击光圈、滚轮和按键提示，可选择按键提示位置；改善工具栏提示及录制标注操作。
- 改善长截图同窗剪辑和剪贴板贴图位置恢复；截图与图片编辑器的 OCR 支持按行框选、追加、排除与恢复。
- 长截图自动滚动根据画面匹配与页面响应调整速度。
- 修正设置文本框的布局和内容裁剪，避免较长文字侵入边框。

OCR 结果过滤默认关闭。整版真实界面验收仍待完成；极小 AVIF 图片存在解码失败，文件音频关闭曾出现偶发超时，录屏字节流故障回调专项尚未通过。真实 HDR、混合 DPI 与高级录屏摄像头端到端尚未验证。

首次使用自动下载 Windows x64 程序与运行库，OCR 模型和字典按需下载。升级前请从旧版托盘正常退出，再点击动作启动新版。
