# raishot

截图、标注、贴图、文字识别、长截图与录屏，一次点击开始。

RaiShot 是 Windows 上的截图工具。点击动作直接框选，首次使用会自动下载程序，之后使用本地缓存。支持 Quicker V1 和 V2。

## 可以做什么

- 截图与标注：矩形、箭头、画笔、文字、马赛克、模糊，支持撤销、重做和裁剪。
- 贴图：把图片或文字放在其它窗口上方，滚轮缩放、调整透明度，支持标题、分组和关闭后恢复。
- 识别：本地 OCR、表格识别与二维码，也可使用翻译服务。
- 长截图：手动或自动滚动采集，支持纵向、横向拼接，裁边与删除中间片段。
- 录屏：录制 MP4 或 GIF，可选择系统声音、麦克风和标注。
- 管理：在主界面查看贴图、截图与录屏历史，设置支持中文、英文和跟随系统主题。

## 开始使用

1. 点击动作，拖出截图区域；在工具栏标注后按 Ctrl+C 复制，Esc 取消当前操作。
2. 框选后按鼠标中键贴图，按 T 识别并翻译，按 L 开始长截图。
3. 右键动作可选择“区域截图”“启动托盘”或“检查程序文件”。

程序运行时，默认 Ctrl+1 截图，Ctrl+2 将剪贴板里的图片或文字贴到屏幕；快捷键可在设置中修改。贴图滚轮缩放，Shift+滚轮精细缩放，Ctrl+滚轮调整透明度，空格显隐工具栏，F2 编辑标题（工具栏收起时），Esc 取消当前操作或关闭贴图。

动作参数可填写 `region`（截图）、`tray`（仅启动托盘）或 `verify`（检查程序文件）。

## 使用要求与数据

适用于 Windows 10/11 64 位系统，需要可用的 D3D11 显示设备。程序与所需运行库自动下载；首次文字识别还会下载模型与字典，请保持联网。Windows N 的录屏功能需要媒体功能包。

OCR 在本机运行；翻译会向所配置的服务发送识别文本或图片。设置、贴图、历史和模型缓存保存在本机 `%LOCALAPPDATA%\RaiShot`。

升级后请从旧版本托盘正常退出，再点击动作启动新版。HDR 截图会转换为 sRGB；多显示器混合缩放仍在持续验证。
