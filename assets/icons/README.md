# RaiShot 矢量图标

工具栏 SVG 使用 24 × 24 网格、1.8 单位描边及圆角端点，默认显示为 20 逻辑像素；主栏及工具面板显示为 20 像素，属性栏使用更小的下拉箭头和调色图标。GPUI 使用内嵌资源并按实际显示尺寸缓存掩码，颜色由主题和选中状态统一控制。新增图标在 `src/toolbar_icons.rs` 注册；无需运行时文件或字体图标库。

`../app.svg` 是托盘标志的矢量源，`../app.ico` 包含 16、20、24、32、40、48、64 像素图层。修改 SVG 后可运行 `python Tools/render-tray-icon.py` 重新生成 ICO；此维护脚本需要 CairoSVG 和 Pillow，正常构建和运行不需要 Python。托盘直接加载 EXE 内嵌 ICO，按系统小图标尺寸选择图层。
