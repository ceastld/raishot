# 表格识别合成夹具

本目录的 14 张 PNG 均为本项目生成。覆盖浅色／深色有线表、斑马纹、粗线、横线表、无线表、空格、合并行列、密集列与两倍像素尺寸。

`ground-truth.json` 包含完整单元格文字和跨度，以及生成文字时的真实轴对齐范围。默认测试把这些范围作为合成 OCR 输入，验证网格、字素分配和输出；不会运行 OCR、下载模型或打开窗口。纯后端验证命令是 `cargo test --lib table_`。

`cargo test --lib table_eval_real_ocr -- --ignored --nocapture` 会复用本机已经校验的 Tiny OCR 缓存，对 PNG 做真实识别，打印当前零模型后端及旧矩阵启发式的单元格 F1、文本 F1、TEDS-lite、CER、耗时和按 tag 汇总。缺少缓存时直接报错，避免为了评测自动下载依赖。真实 OCR 指标只作观测，不以合成字形上的识别率替代真实截图验收。

此集合是可移植的最小回归集。真实表格截图与可选结构模型对照仍待补充；当前结果不足以决定默认启用 SLANet。
