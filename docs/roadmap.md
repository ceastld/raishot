# RaiShot 长期开发计划

本文件只保留路线与功能差距，当前使用方式见[功能说明](behavior.md)。功能完成后只更新下表对应行，不在此追加过程记录。

媒体查看、录屏与工具的后续主线见[整体优化计划](references/media-viewers-recording-tools-plan-2026-10-22.md)：包含格式目标、114项可认领任务、依赖、文件所有权和新对话指令。先打通普通文件/历史视频的有声播放，再推进图片查看、录屏质量与工具；新能力可先内部开发，人工验收后逐项开放。

## 功能对照

按截图工具的常见能力整理工具集合、工具栏按钮、全屏截图窗口与设置项清单，按行为独立实现。

“工具可选择”只代表入口存在。每项能力分别核对参数入口、绘制与取消、已有对象编辑、预览与输出、截图与贴图复用；缺少其中一环时保留具体差异。下面的历史交付记录只证明当时列出的验收范围，不能代替新发现的参数和交互缺口验收。

## 细节功能清单（2026-10-19）

根据 RaiShot 的使用场景和当前源码整理，只列**缺失或只做了一部分**的功能，已完整具备的不再列出。优先级：P1 高频且明显缺失；P2 有用、可排在 P1 之后；P3 低频或成本高。完成一项后把该行改为“已有”并在下一次整理时删除。

### 贴图内容类型

剪贴板贴图目前只认三类来源：PNG／图片、剪贴板里的本地图片文件、纯文本（`pin_app.rs::clipboard`）。其它来源要么退化成纯文本，要么报错。

| 功能 | 现状 | 优先级 | 要点 |
| --- | --- | --- | --- |
| 富文本／HTML 贴图 | 缺：网页、Word、WPS、代码编辑器复制的内容只取纯文本，颜色、字号、粗斜体、背景、列表、表格全部丢失 | P1 | 读取剪贴板 `HTML Format` 片段，不引入浏览器运行时：解析为“段落＋样式片段”（字体、字号、颜色、粗／斜／下划线／删除线、背景色、链接、列表、`pre`/`code`、简单表格、内联图片），用现有文字排版绘制。最大宽度默认约 800 DIP 自动换行，固定宽度或不可断行内容整卡缩小而不是截断。右键“忽略格式”切回纯文本；复制同时给 HTML 和纯文本；文字可选择、可拖出。前置条件：文字标注支持局部样式片段（目前只有整对象格式） |
| 文本贴图排版设置 | 部分：字号固定 22、不按最大宽度换行，无内边距、字体、颜色设置；底色与默认文字色只随主题 | P1 | 设置 ▸ 贴图 ▸ 文本：最大宽度（超出换行）、内边距、字体与字号、文字色／底色（默认仍跟随主题）、新建时是否默认可选文字 |
| 颜色贴图 | 缺：`#RRGGBB`、`rgb()`、三个数值、颜色英文名会贴成普通文字 | P2 | 显示色块和数值；右键转 HEX／RGB／HSL 复制；Ctrl 拖出颜色文本 |
| 文件贴图 | 缺：剪贴板文件只找第一张本地图片，没有图片时报错 | P2 | 一张贴图列出一个或多个文件（图标＋文件名）；打开、复制文件／路径、在资源管理器中显示、Ctrl 拖出文件 |
| 动图贴图（GIF／WebP） | 缺：只取首帧 | P2 | 按帧时间播放，可暂停与逐帧；标注和 OCR 作用于当前帧；工作区保存原文件 |

## 架构约定

1. Annotation / Document / Editor / Scene 是核心边界，GPUI 只转发事件和绘制。新增基础工具扩展几何与共同渲染，避免把所有逻辑塞进窗口。
2. 一次手势或批量操作对应一个增量命令；无变化不清除重做，取消不写历史。选区与对象文档独立。
3. 非破坏编辑保持冻结原图和对象。套索/局部擦除应作为可撤销蒙版；组合/旋转应扩展对象变换，不能简单把截图烘焙后覆盖底图。
4. 场景下层复用，修改下层使后续效果失效；预览、导出和识别输入使用同一合成数据。普通路径允许抗锯齿差异，像素效果必须一致。
5. 常驻只管理原生托盘。贴图、识别、采集和编码按需拥有独立生命周期；任务取消、错误和旧异步结果都必须可处理。
6. 不把“Rust/GPUI”作为性能证据。先测首帧、拖拽、合成、输出、托盘和活动内存，再优化热点。外部 D3D 纹理导入当前没有公共 GPUI 接口，不做未经验证的零拷贝承诺。
