# 工作流程

先读项目根的 `AGENTS.md`，从[文档导航](README.md)定位任务。本页说明贡献者和 agent 共用的协作、运行与记录方式；路径和命令均相对项目根，项目开发不要求私有资料。

## 编译与测试（最重要）

- **只在主工作区 `target/` 增量编译。** 禁止复制工程、建隔离源码快照、用新的 `--target-dir` 或 `target/qa/*` 下的副本编译——每个新目录都要从零编译 GPUI 依赖，十几分钟起步。仅当用户明确要求时例外。
- 验证顺序，够用即停：
  1. `cargo check`（或 `cargo check --bin <名>`）确认能编译；
  2. `cargo test --lib <过滤词>` 只跑受影响模块的测试；
  3. 需要实际运行时 `cargo build` 后按“本地运行”重启。
- **本地默认只用 Dev（`target/debug`），不编译或运行 Release。** Release 默认由 CI（`.github/workflows/release.yml`）负责；只有用户明确要求“本机编译 Release”时，才可在本机运行 `cargo build --release`、`build.ps1` 或 `verify.ps1`。要求发版、提交或提交前总检查不视为本机 Release 授权；测试不要加 `--release`。
- 全目标 `clippy -D warnings` 只在用户要求发版或提交前总检查时运行。
- 格式化只对自己改的文件：`rustfmt --edition 2021 <文件>`，不跑 `cargo fmt --all`。
- 编译失败若来自其它会话正在改的文件：说明一句，不替别人修，不反复重跑等待；能用 `cargo test --lib <过滤>` 绕开就绕开，否则把源码改完并标注“未编译验证”。
- 已通过的检查在相关代码未变时不重跑；不生成源码清单、哈希、来源身份文件或包装 runner 脚本。

## 本地运行

- 增量 `cargo build` 后，把 `target/debug` 的三个 EXE 复制到 `target/qa/tray-run/`，结束本仓库启动的 raishot 进程，再从 tray-run 启动托盘（直接从 target/debug 运行会锁住文件导致其它会话链接失败）。复制前确认 EXE 时间晚于修改。
- 界面类修复验证受影响的拖动、遮罩、取消、焦点与多屏交互，说明真实界面验证范围。维护者若已有本机 `target/qa/flicker-probe`，可运行 `--drag-test 3` 辅助观察；它不是公开构建或贡献的前提。无法完成真实交互时写明“真实界面未验”。
- 用户电脑在持续使用：不要求桌面空闲，不反复弹 QA 窗口，不为展示图片／OCR 样本打开窗口。
- **所有测试／预览／原型窗口跟随 Windows 主题；系统深色时禁止白色或高亮底窗口。** 自写 HTML 默认深色并响应 `prefers-color-scheme`；内置浏览器打开本地文件只能浅色渲染，所以不要用它预览本地文件。

## 记录（少而准）

- 一个任务完成或告一段落时，在 `docs/status.md` 更新对应条目，用 3–5 行说明现状、实际验证和下一步；行为或快捷键变了再改 `docs/behavior.md`，路线变化才改 `docs/roadmap.md` 对应表格行。
- 详细设计和取舍写到 `docs/references/<专题>.md` 一处，选型与研究写到 `docs/research/`，其它地方只放链接。不写会话号、文件数、快照名、PID 等流水，不把同一过程抄进多份文档。
- 任务彻底完成且无后续时，从状态页移除，长期结论留在专题。状态页过长时先压缩或移除已完成项，不让新贡献者依靠原始会话记录还原项目。历史实验只证明其当时输入与版本，不代表当前代码已经通过验证。
- 长期目标在一项完成后直接继续下一项，不需要额外的确认或协调消息。

## 并行协作

- 多会话（含不同开发应用）共享一个工作区和主 `target/`。开始改某文件前看它最近是否被改（`git diff <文件>`）；避开别人正在改的段落，只有同一共享代码段需要短暂交接。
- **cargo 串行，源码不冻结。** 已有 cargo（看到 `rustc.exe`）占用主 target 时继续写代码，不终止其它会话的编译，不排队第二个 cargo、不轮询等待；误入锁等待只取消自己的。验证只覆盖该次构建，后续改动进入下一批。
- 分派子任务时写清允许改的文件和交付内容；子任务只报告改动、跑过的命令和结果、未验范围。共享入口（`lib.rs`、`Cargo.toml`、工具栏注册）由一人改。
