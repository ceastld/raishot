流程：本机识别 + 只发文字

  1. 复用当前来源的 OCR 结果；没有时先走现有 ppocr 识别和扫描动效，不重复识别。
  2. 按段落合并规则把识别行组成“翻译块”；标题、列表项、按钮、提示框各成一块。代码、网址、纯数字和已是目标语言的块跳过。
  3. 逐块请求现有 OpenAI 兼容接口（设置 ▸ 翻译的端点与模型），并发 3、单块超时 20 秒；按阅读顺序落图，先完成的先显示。
  4. 请求里只有文字和目标语言；图片、剪贴板不离开本机。会话内按“原文 + 目标语言”缓存，切回同一语言不再请求，不写磁盘。

译文层：矢量、可编辑、所见即所导

  • 译文层是文档里的一个组，每块记录原文、原文四角、取样底色、文字色、字号（自动或手动）和状态；第一次出译文时整体作为一条撤销记录加入。
  • 预览和复制、保存、贴图共用同一份数据，导出时才渲染成像素；描边、旋转圈、操作条和面板都不进入导出。
  • 与标注一样用全屏坐标：移动或重选选区不平移、不清除译文；选区外的块不导出。
  • “转为普通标注”把每块拆成填充矩形 + 文字标注，之后用普通工具编辑，一次撤销。
  • 取样颜色来自截图像素，不随浅色／深色主题变化。

取色与排版

  • 底色：识别行外扩 2 px 的环带取中位色；环带方差大（渐变、照片）时改用周边像素的平滑填补，面板标“复杂背景”。
  • 文字色：块内与底色差异最大的主色簇；粗细由笔画宽度判断，对齐由各行左右边距判断（按钮居中）。
  • 字号：从原行高推算，放不下时每次缩 0.5 px，最小 9 px；仍放不下则向下延伸并标“超出原区域”。
  • 倾斜文字沿原四角放置；竖排文字第一版保持原样不覆盖，面板说明原因。

动效时间线

  • 0 ms点“翻译”：按钮进入选中态，面板从右侧淡入并显示骨架。
  • 识别无现成 OCR 时扫描光带扫过，识别行框依次淡入。
  • 翻译每块显示虚线框与小转圈，原文保持可见；完成一块就以 320 ms 淡入译文，面板对应卡片同时出字。
  • 完成行框淡出，标题栏显示“段数 · 用时”，提示跳过和失败数量。
  • 识别或翻译中按 Esc 立即取消请求，撤回本次未完成的译文层，不留残块。

面板目标语言下拉默认取设置中的 translateTarget；这里改动只作用本次，菜单里可“设为默认”。切换后只重新翻译，不重新识别；已手改的块会先在面板内确认是否覆盖。

按键Enter / Ctrl+C复制含译文的图片并结束截图，与普通截图一致；“复制译文”按阅读顺序复制纯文本。

待定问题

  • 中译英、德语等变长语言：缩字到 9 px 仍放不下时，是向下延伸、向右延伸还是缩行距，需要用真实截图样本决定。
  • 接口目前一次一段文本；若改为批量请求，需要可靠的分段标记，避免模型合并或丢段。
  • 复杂背景的填补质量（渐变按钮、照片上的字幕）是否需要单独的修复模型，还是先只提供“半透明底”选项。
  • 局部重识别改变某行原文后，对应块标为“原文已变”并提示重译，还是自动重译。
