放不下时怎么收

  • 可用宽度 = max(选区宽, 主栏宽)，再受屏幕宽限制。每一级都按“外观｜专属｜对象”整组换行，两行放得下就停在这一级。
  • 第 0 级 全部展开。
  • 第 1 级 分段收成下拉：线型、填充、叠加、笔迹；箭头两组合成一个显示当前端点的下拉；文字只留粗体，其余字形和对齐收进“文字样式”。
  • 第 2 级 8 个色块收成一个颜色按钮，弹层里是 10 色、最近使用和自定义。
  • 第 3 级 专属组收进“样式”弹层（逐行标签 + 原控件），不透明度并入颜色弹层；“完成选择”和说明文字不收。

交互细节

  • 数值框：单击开弹层（数字输入、滑杆、常用值）；滚轮 ±1 步，Shift ×5，700ms 内连续滚动合成一次撤销；按住左右拖动连续调，松手算一次撤销。
  • 色块：单击即改并提交。自定义打开取色器，拖动只预览，确定才提交并记入“最近使用”，Esc 或取消恢复原色并回到上一层。
  • 不可用的分段和按钮仍能悬停，提示里写原因，例如“尖尾箭头不支持虚线”。
  • 弹层同一时间只开一个；下方放不下翻到上方，左右夹在屏幕内。
  • 文字描边、底色是拆分开关：左半开关，右半 ▾ 打开细项；在细项里改颜色会顺带打开开关。

落到 Rust 侧

  • capture_toolbar.rs 的 Palette 增加上表 7 个颜色，深浅各一。
  • 新建共用控件（如 toolbar_widgets.rs）：icon_button、segmented、swatch_row、value_field、dropdown、split_toggle；截图与贴图（pin_property_bar.rs）共用。
  • capture_properties.rs：颜色行换 swatch_row；property_selector 换 value_field，保留滚轮；各芯片按上表换控件；箭头预设拆成端点 + 头型。
  • toolbar_layout.rs：按控件实际宽度估算（色块 26/格、分段 26n + 2(n−1) + 4、数值框按最大值字符数），从第 0 级逐级尝试。
  • 弹层：数值弹层加滑杆和数字框（可复用 capture_color_dialog.rs 的色相条拖动）；取色器按本稿换皮并加“最近使用”。
  • toolbar_icons.rs：补端点、头型、叠加、对齐、字形、描边、底色、框选区域、删顶点、闭合、排列菜单等图标，本页 <symbol> 可直接转路径。

需要模型改动的提议

  • 点线：Style.dashed: bool 改为三值线型（实线、虚线、点线），渲染、导出、命中同步。
  • 吸管：取色器里从冻结画面取色，可复用 capture_color_pick.rs 的取色判断。原型按钮未接。
  • 最近使用：保存最近 10 个自定义颜色到偏好。
  • 数值框拖动调值与 打码区域分段只是界面，模型不变。
