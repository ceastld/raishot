新方案的规则

  • 单击：光标出现在点击处（竖直居中于点击点），不再先画 300×60 的框；虚线框只包住文字，随输入向右长，不自动换行。
  • 拖一下：拖出的宽度就是换行宽度，高度随内容。
  • 右边缘小柄：拖动改为固定宽度并换行；双击小柄回到自动宽度。
  • 单击已有文字：直接把光标放到点击位置继续改；按住拖动则移动。选择工具下双击进入编辑。
  • Ctrl+滚轮：编辑或选中时调字号，属性栏同步。
  • 编辑态与完成态位置、内边距完全一致，提交时文字不跳动；空文字提交即删除。

保留的合同

  • Enter／Ctrl+Enter 完成、Shift+Enter 换行（上方可切换对比“Enter 换行”）。
  • Esc 保留正文并结束；正文已空再按 Backspace 结束并移除。
  • 输入法组字期间所有快捷键让行。

落地时的性能处理

  • 每次按键现在会 TextLayout::new 重排并两次递增 preview_revision，使整层标注预览失效；改为只重排草稿本身，草稿单独绘制，不进入已提交标注的缓存。
  • 自动宽度按单行测量即可，不再按 300 宽度做换行排版。
