选区外观条三种交互，选一种实现

截图后选区左上的外观条。舞台可直接操作：悬停预览、单击应用、滚轮切换，拖选区左上角的菱形改圆角。

现在这一版哪里不顺手

  1. 一个按钮两种行为：主体是开关，右侧 16px 的窄箭头才调参数，常点错。
  2. 三个效果图标长得像，开着的都是同一片绿，看不出最后导出会是什么样子。
  3. “圆角＋阴影”这种最常用的外观要点两三下；参数分散在三个浮层里。
  4. 圆角已经能在画布上拖菱形，条上再放一个圆角按钮是重复入口。

颜色圆点在原型里单击轮换几种颜色；实际实现打开现有的取色浮层。

三种方案都遵守

  • 样式是完整快照：缩略图、选区预览、导出三者一致，没有隐藏的记忆开关（不再出现“原样下圆角置灰”）。
  • 拖到 0 就是关：阴影扩散、边框粗细为 0 即关闭，不再单独放开关；边框最小值由 1 改为 0。
  • 每个样式记住自己的调整值，可“恢复默认”；下次截图沿用上次选的样式。
  • 调外观不切工具、不进标注撤销；导出、复制、贴图仍只读当前生效的外观。
