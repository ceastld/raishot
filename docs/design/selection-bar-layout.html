新算法规则

  1. 锚点是选区左上角。每个候选的得分 = 条到锚点的最短距离 + 方位罚分，选最小的。
  2. 候选来自选区四周和障碍物边缘：选区上方／下方／左外侧／右外侧／内侧左上，再加上紧贴主工具栏、属性栏、OCR 面板边缘的位置（叠在工具栏上方或接在它右侧）。
  3. 硬约束：完全在显示器内（留 4px）；不与主工具栏、属性栏、OCR 面板相交（留 4px）；不能骑在选区边框上，要么在选区外留出控制点间距 8px，要么完全在选区内侧。
  4. 方位罚分：上方 0，左外侧 24，下方 32，右外侧 40，压在选区内 400（挡内容，外面放不下时才用）；只省样式名的显示另加 8，只留缩略图另加 16。
  5. 修旧问题：旧算法把 8 个控制点当障碍，贴着工具栏的位置常因与右上控制点差零点几像素相交被否决，于是退到屏幕角落。新算法改用“选区外留间距”的边带约束，不再单独避让控制点。
