# 媒体音频输入与倍速处理

录前输入检测只由显式按钮启动；打开音频面板和刷新设备列表不采音。原始包的音量表先于增益及重采样，设备初始化和释放都在后台；关闭完成回执晚于设备释放，开始录制等待该回执。录前混音值限于0–400%，只用于本次成片，辅助WAV保留原始音轨，预览和覆盖保存按真实已烘焙基线计算，见[输出生命周期](recording-output-lifecycle-2026-10-11.md)。

视频默认仍为变调及标准重采样。实验保调采用48kHz WSOLA，窗口约20ms、步长10ms、搜索范围±5ms，左右声道使用相同偏移；输入最多250ms。标准为线性重采样，高质量为64tap低通sinc，先将原生PCM转换到共用混音网格，再转换到设备采样率。变调时网格由源采样率、设备采样率及倍率确定，避免慢速播放前先丢弃会移入设备通带的高频；保调仍固定48kHz。菜单分别显示请求的倍速处理和采样质量，换视频恢复默认。

seek、倍速、暂停和欠载均重建处理状态。解码预读不计为已播放；媒体尾按真实EOF夹紧，只有设备ReleaseBuffer成功后提交交付时间。最终提交持锁读取最新静音和音量，处理及滤波尾部也受同次设置约束。失败只属于实际操作代次，新配置可重试；重建输出延续已播位置与设备时钟代次。音频错误期间视频继续前进时，显式更换处理设置从当前视频位置重新定位，保留播放意图；逐帧定位中的错误恢复需稍后重试。

调整录屏分轨音量后，保存入口以半秒PCM块重混，短分轨补零，不整段载入WAV。当前文件须新鲜核验为H.264，压缩视频样本保持原样；外层暂存、取消与发布仍由[输出事务](recording-output-lifecycle-2026-10-11.md)负责。

接管集成后的 Dev `cargo check --lib --tests` 通过，视频／录屏／音频／媒体四组排重定向共562项通过、29项按设计忽略，其中音频组177项通过。共用网格、最终音量、错误恢复与分块WAV相关普通回归均通过。原生检查另通过分块重混、静音设备时钟、5.1下混、输入检测回退与关闭、文件音轨切换和失败恢复五项；重混的30个压缩视频样本逐字节、时间与时长相同，AAC幅度符合两套混音设置，取消后原片与WAV不变。
