# 剪贴板原位贴图、透明像素与鼠标缩放

## 行为

- 截图复制同时保存导出图左上角的虚拟桌面物理坐标；位置包含选区外观 padding，支持负坐标、跨屏和贴边。剪贴板再贴图优先按该位置、原尺寸打开，显式 `--at` 仍优先。原位置完全落在当前显示器之外时回退到可见工作区。
- 普通图片按实际 alpha 逐像素透出桌面；透明通道全为 255 时自然保持不透明。半透明、内孔、边缘留白都保留，不按颜色抠背景，也不把普通白底图片变透明。图片编辑器仍用棋盘显示透明区域。
- 截图复制后的外观已经合成进 PNG，再贴图只作为普通图片显示，不重新套截图外观或矩形窗口阴影；需要继续编辑矢量标注时仍用截图直接贴图入口。
- 滚轮默认锚定鼠标。已有配置中明确选择的左上角／中心保留；缺失、非法配置用鼠标位置。工具栏固定倍率继续沿用其原有锚点语义。

## 实现与取舍

`export.rs` 在同一次剪贴板写入中发布 PNG、DIBV5、白底兼容 DIB 和 `RustShot.ScreenPosition.v1`。私有位置记录带版本、PNG 原始长度与摘要；读回只接受匹配的 PNG，避免剪贴板管理器残留旧私有格式造成误定位。普通软件仍按原有图片格式粘贴。PNG 和位置在同一次剪贴板锁内读取，分配读取有上限，坏元数据只丢弃位置。

复制入口在 `capture_view.rs` 与 `capture_quick_action.rs`，共用 `finished_origin`。文件编辑不产生截图位置。`pin_app.rs` 读回有效位置后经 `PinView::open_copied_capture` 保留物理位置与自然尺寸，不能再次适应到单屏而移动或缩小跨屏截图。

资源管理器复制的图片文件使用 `CF_HDROP`，不能把 GPUI 拼接的文件名当成纯文字。剪贴板入口在图片数据之后识别文件列表，打开首个可读图片并保留 alpha；读取前跳过未落盘的 Offline／Recall 占位文件。已在本地的云盘图片与其它目录一样可以读取。普通图片仍保留可手动切换的窗口阴影。

透明像素此前被三层显示逻辑挡住：无外观窗口使用不透明交换链、宿主铺深灰底、标注画布生成棋盘预览。`pin_view.rs` 统一透明合成并移除图片底色，`capture_canvas.rs` 仅非贴图画布铺底色，`canvas_source.rs::shared_pin_image` 为普通贴图保留原始 alpha。超长图只生成有界预览，按预乘颜色与 alpha 进行面积缩小后恢复 straight BGRA，完全透明像素的隐藏 RGB 不污染边缘；局部擦除恢复同样保留 alpha。文字贴图仍绘制主题纯色底。透明像素不会自动启用整个窗口的鼠标穿透，原有操作入口保留。

`pin_zoom.rs::PointerAnchor` 保存连续滚动起点的屏幕坐标和原图坐标，最终 HWND 定位才舍入；鼠标移动、窗口移动、投影变化、拖角或其它定位后重新建立锚点。与左上角缓存一样支持同帧合并。鼠标缩放继续走已有预备底图、调整窗口、立即绘制首帧、同步阴影的顺序，细节与既有一帧左右的时序限制见 [贴图缩放延迟](pin-zoom-latency-2026-10-16.md)。

## 验证

定向模型覆盖位置与 PNG 绑定、外观 padding／负坐标、普通与超长透明图、预乘采样、连续鼠标锚定及移动后重建。`pin_presentation_smoke` 增加 `RUSTSHOT_PIN_ALPHA_QA=1`，从实际 PNG 解码到无外观贴图，读取首显、画布接管和缩放后的自有 GPU 像素；`pin_zoom_timing_smoke` 固定屏幕鼠标点并核对原图点与首帧延迟，摘要直接输出到 stdout。

- `cargo check --bin kirie-gpui` 通过；`cargo test --lib pin_zoom` 17 项通过，复用同一库测试程序按 `canvas_source::tests`／`clipboard_position`／`alpha_clipboard` 过滤的 23 项通过。合计 40 项，无失败；系统剪贴板未被修改。
- 实际 0.4.10 Release 包的透明专项中，普通 PNG、画布接管后、1.5 倍缩放后三组各检查透明、半透明与不透明像素，9 项自有 GPU 预乘 BGRA 均符合原图 alpha，原尺寸和物理位置也通过；没有修改系统剪贴板。但前台保护检查报“QA 把用户前台窗口切换到自己的贴图”，因此总验收失败，不能记为专项全部通过。
- 同一 Release 包的固定鼠标点缩放计时专项完成 19 步，摘要通过，最大锚点误差为 0.0000172 物理像素。59 Hz 下，滚轮到窗口调整的中位数／P90／最大值为 15.64／20.52／28.50 ms，滚轮到内容显示为 25.18／34.63／40.23 ms，窗口调整到内容显示为 9.76／12.53／18.38 ms；`stale_presents=9`，尺寸与内容不一致最多持续 2 个刷新周期，不能宣称缩放无闪烁。当时没有本任务的 Release 编译负载，其它桌面负载未控制。
- 三轮拖动遮罩探针仅运行一次，因 `target/qa/flicker-probe` 未找到可运行项目而未完成；真实资源管理器文件复制、剪贴板繁忙、多屏混合 DPI 与连续缩放视觉表现仍未验。未结束其它会话，也未为失败项重跑。
