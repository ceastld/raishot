# 录屏输入显示（点击、滚轮、按键）

实现：`src/input_overlay.rs`。

## 录时合成，不做录后合成

效果在录制线程里逐帧合成进视频帧（与摄像头、实时标注同一 CPU 帧路径），停止即得成片。

不改为“录制原始画面 + 事件轨，导出时再合成”的理由：

- 录后合成要求每次导出都完整解码再编码一遍，长录像收尾要等几十秒到几分钟；当前停止后立即可预览、保存、复制文件。
- 原位预览、转 GIF、复制文件都直接用成片文件；改成后合成后，这些入口都要先合成或在播放器里实时叠加，牵动面大。
- 录后合成的好处（录完可改样式、可关闭效果）要等有了视频编辑与重新编码导出之后才有意义。届时可以在录制时额外写一份事件轨（时间、坐标、按钮、按键），不影响现有成片。

“录的时候看不到效果”改用屏幕同步小窗解决（见下）。

## 样式

数值为 DIP，按选区所在显示器的 DPI 放大。

- 按下：半径 12 的半透明实心圆（不透明度 12%→26%）+ 2 宽描边 + 外侧细白边（同色背景上也能分清），110 ms 从半径 17 收拢；跟随当前指针，拖动时也在。漏掉松开事件时最多保留 10 秒。
- 松开：从松开处外扩到半径 32，描边由 2 变细到 0.8，460 ms 淡出；实心核在前 45% 散开。只对见过按下的松开外扩。
- 颜色：左键 `#3D8BFD`、右键 `#F5A524`、中键 `#A66CFF`、侧键 `#8FA3B0`。
- 滚轮：指针右下（+26, +24）的 18×28 深色胶囊（水平滚动时横放），两道白色箭头指向滚动方向，每格从后方滑入；续滚和换向不重新淡入，最后一格后停留 380 ms 再 220 ms 淡出。
- 按键：位置在按键显示下拉里选，可选左上、右上、左下（默认）、底部居中、右下，存为 `recording.json` 的 `key_position`；距边 22，最新一行贴边，旧行向内堆叠，各行按所在侧对齐。每行一枚深色胶囊，组合键逐个画成键帽，“×N”用次要色；最新一行贴所选边缘，旧行向内堆叠、72% 不透明度；淡入 120 ms，到期前 350 ms 淡出。文字先以白字黑底画成灰度遮罩，再按行透明度着色。
- 指针画在光圈之上，按键提示在最上层。

所有图形用有向距离逐像素抗锯齿画进预乘 BGRA 小图层，只覆盖效果所在的外接矩形，再叠到帧上。

## 屏幕同步小窗

开启点击显示时，钩子线程上另建一个分层小窗，持有一份独立的效果状态，按同一事件流演进、用同一套图层绘制，大小只覆盖当前效果并裁到选区内：

- 排除采集、鼠标穿透、不激活、置顶；远程画面兼容模式下工具窗不排除采集，此时不建小窗，以免成片里叠两份。
- 钩子回调只记账和起 15 ms 计时器，绘制在计时器里做，不拖慢系统输入；空闲时隐藏并停表。
- 录制线程出帧时置“正在录制”，倒计时、暂停期间为否，小窗随之清空隐藏。
- 只同步点击与滚轮；按键提示贴在选区边角，同步到屏幕会挡住正在操作的内容。

## 验证

- `cargo test --lib input_overlay`：图层裁剪与合成、点击／滚轮状态机、按键合并与过期、五种按键位置的落点。
- 静帧对照（调样式用）：`RUSTSHOT_OVERLAY_PREVIEW=<png> cargo test --lib recording_overlay_preview -- --ignored`。
- 小窗冒烟：`cargo test --lib recording_input_mirror_smoke -- --ignored`，在主屏左上角跑一次点击，确认显示位置、排除采集、空闲隐藏停表、暂停不记效果、释放销毁。
- 真实录制中的观感与成片效果待自然使用验证。
