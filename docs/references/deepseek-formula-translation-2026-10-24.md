# API 公式识别与翻译

默认使用 `https://api.deepseek.com/v1`、`deepseek-flash`。公式识别只在点击识别时上传当前选区图片；文字翻译只发送所选文字。请求明确关闭思考模式，使用现有系统代理，HTTP/SSE 失败不偷偷切换服务。原本精确匹配旧内置默认值的配置迁移到新默认，自定义地址、模型及关闭状态保留。

## 设置与凭据

设置 ▸ 翻译可以填写 API Key，输入框默认遮蔽；服务改动点击应用后保存，不触发联网。内存中保留请求所需的明文，磁盘用 Windows DPAPI 按当前用户加密；无法解密时保留旧密文并提示重新填写。取消草稿及跨页面保存不会把别处更新的 Key 覆盖成旧值。安装包和源码不带维护者凭据。

## 公式

识别下拉选择公式后，结果面板原位停靠在截图／图片编辑器内，不再打开独立窗口。任务持有发起时的选区快照，重试仍使用这张图片；关闭或取消撤销本次请求，来源变化或迟到回执不能安装旧结果。

结果按 Markdown 混排普通文字、行内／独立公式和表格。API 原文完整保留，兼容源文只去掉完整包裹全文的代码围栏，保留数学定界符和换行；每个数学段独立校验、排版，局部错误显示对应源码及诊断，其余文字、公式和表格继续显示。括号、环境、危险非数学命令及空白基底的可疑花括号标签仍会拒绝；截断、超长等生成异常保留源文并提示校对，不猜测或重写数学含义。

源码页是保留换行的多行编辑器，Enter 换行、Ctrl+Enter 提交；编辑只在本机重新解析、排版，不重复调用 API。“复制 LaTeX”按文档顺序提取公式，“复制源码”保留当前完整 Markdown 源文及换行，“复制图片”导出文字、公式和表格的整份排版结果；存在待校正内容时保留源码供修正，不输出残缺图片。RaTeX 与内嵌数学字体负责本机数学排版，中文使用系统字体并检查缺字；不要求 TeX、Python 或 WebView。上传、源码、嵌套、排版块和预览／导出像素均有上限，屏幕预览跟随亮暗主题。

完成后的 API 译文复用同一 Markdown 组件，支持文字、公式和表格；普通 OCR 仍保持文字／段落，不自动推断表格。主动表格识别和结构化译文继续使用已有本地网格及单元格保护。

## 翻译和表格保护

普通文字 OCR（包括图片编辑、贴图和普通重试）不检测或缓存表格，结果只展示文字／段落／译文。用户在识别菜单主动选择表格、文字面板“更多 ▸ 识别为表格”、表格复制快捷动作或贴图“复制表格”时，才运行本地表格结构任务并展示表格页。普通 OCR 只保留可供后续主动识别使用的原始输入；主动表格结果的重试仍运行表格任务。

翻译前在本机遮蔽代码、数学片段、链接、占位符和数值，回执须完整且唯一保留保护标记。普通流式预览不暴露半个标记；结构化请求先验证再展示，不显示内部 JSON。

主动表格识别继续使用本地 SLANet_plus／规则和 OCR。单元格按稳定 ID 发送文字，必须返回完整、唯一、已知的 ID。回执只更新本机网格的文字；边线、行列、空格、跨度、位置和置信度原样保留，数值及空单元格不由模型重写。独立表格全文翻译在译文页显示网格，复制同时写 TSV 与含合并格的 CF_HTML；图片翻译默认本机识别加文字 API，已有主动识别的结构化表格时导向单元格译文，避免覆盖边线。显式选定的图片翻译引擎保持该选择。HTML 单元格统一文本格式以保护 OCR 字符串；Excel 中需要求和时再由用户转换数值类型。

混排正文含不符合 TSV 转义规则的引号时，会保留原文并拒绝翻译，避免猜测字段边界；合法表格 TSV、单元格内转义引号及普通无表段落不受影响。正文混排译文复制为 TSV；含合并格的 HTML 复制适用于独立表格译文。
