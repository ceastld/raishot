# 翻译设置入口

当前默认服务、API Key 保存、公式预览及表格翻译保护见[API 公式与翻译](deepseek-formula-translation-2026-10-24.md)。下文保留设置交互的设计背景。

设置新增“翻译”分类，使用现有 Preferences 的接口端点、模型与目标语言三字段。表单先编辑草稿，应用时读取最新完整配置、仅替换这三字段，再沿现有保存入口提交；其它设置保存也保留最新翻译字段，避免旧设置窗口覆盖它们。验证或写入失败保留草稿与旧内存配置。“取消修改”重载已保存值，“恢复默认”只更新草稿。空端点关闭服务，空模型／目标沿原默认语义，现有 INI 与显式翻译入口兼容。

端点仅通过现有 ureq 的本地 URL 解析，限定 HTTP／HTTPS、无查询或片段；保存不做 DNS、HTTP 或翻译请求。实际翻译仍由用户显式触发，沿既有仅发送文字的协议。本阶段没有增加依赖或改变 OCR 下载。

三个字段使用可选设置输入模式；原普通／水印 TextField 保留旧协议。首次输入法组合保存完整正文与选区方向，取消／失活／失焦恢复原检查点，确认或程序重置清掉旧检查点。Tab／Shift+Tab 按三字段顺序移动，组合期、重复键和额外修饰键不切焦点；占位文案在同一实体绘制时读取当前语言。三个原生突变回调在设置模式下还要求窗口 active 与自身 focus，阻止取消后晚到的空替换再次删除恢复选区。

三个目的已实际最小合入，完整782→783、仅一新模块，原与后继52附件保持。此前原生晚到回调缺口与作者第一次CRLF补丁生成失败均保留；最终窄审确认实际回调门可达，静审不代替运行验证。

四个发布合同与四个输入决策模型共8项均在当前生产库实际检查自然0、主库编译0、双流排空，完整783及测试EXE前后稳定。前一编译因无关测试夹具数值类型不明确为101，8模型当时未执行，原失败保留；修正后只运行必要8项，不重测旧正确功能组。真实 Windows IME、焦点、语言切换、设置布局与磁盘写入失败仍待验；当前未安装或发布。此功能不进入已经固定的OCR阶段778候选，后续统一候选单独核定。长期目标active，默认后台，不要求电脑空闲。

## 流式输出（2026-10-13）

纯文本翻译改为 `stream: true`：`translate::translate_stream` 逐行读 SSE `data:`，累积 `choices[0].delta.content`，思考段未闭合前不显示；流中 `error` 对象转为错误文案；响应不是 `event-stream` 时按原整段 JSON 解析。`spawn_stream` 在独立线程运行，部分译文最多每 40ms 推送一次完整快照；`Translation::progress` 只接受当前请求的 Pending 预览，被拒绝（请求过期／正文变化）时 UI 丢弃接收端，线程下次回调即停止读取。复制仍只在 Done 后可用。图片翻译逐块批量插入，继续用非流式 `translate`。默认服务实测约 1/6 概率返回 200 空流，`translate_stream` 在未收到任何片段和 `[DONE]` 时自动重发一次。

## 目标语言下拉与高级折叠（2026-10-16）

用户反馈：翻译页本质上只需要让用户选“译成哪种语言”，端点、模型这类参数不该在首屏。原型 `docs/design/translation-settings.html`（https://claude.ai/artifact/K5ADYAeFMDCGgfMQYaJ6xG ）。

- **首屏只有“译成”**：下拉即选即存（`save_translation_target`，只改 `translate_target` 一项，与主题／语言同路线），不进草稿；`TranslationDraft` 不再含目标语言，“应用”也不会覆盖它。
- **菜单**：GPUI `deferred(anchored())` 浮层，右上角对齐触发器下沿；同时铺一层透明全窗遮罩（优先级低于菜单）接住菜单外的按下并关闭，避免“点触发器 → mouse_down_out 关 → click 又开”的来回。顶部“自动”写明规则；两列 14 种语言来自 `translate::LANGUAGES`（代码、母语名、中文名即提示用名、英文名），提示词与菜单共用一张表，新增越南语、泰语、印尼语；中文界面里中文变体不重复副标题。末项“其它语言…”打开输入行，`parse_target` 把认得的代码、母语名、中英文名归到菜单项，“自动／auto”写 auto，其余原样保存；空输入提示而不保存。
- **高级两行**：翻译服务与图片翻译各一行，折叠时徽标 + 一行说明显示**已保存**状态，展开才见分段与输入框；自定义从内置／关闭切入时若框里还是内置地址就清空，避免误以为已填好；自定义空地址现在是校验错误（原先会静默变成关闭）。
- **应用条**：`TranslationDraft::changed` 用同一 `candidate` 把草稿和已保存值各算一遍再比五项，内置且模型留空、末尾斜杠等等价写法不算改动；校验不过算改动，让用户看到错误。
- **恢复默认**：目标语言即时复位为自动（它本来就是即时项），服务默认值只进草稿。

- **键盘**：打开菜单时焦点给菜单，方向键按“自动 → 两列网格 → 其它语言”移动（`menu_step`），回车／空格选中，Esc 关闭不改值。

局限：打开菜单时遮罩会挡住滚轮。`cargo test --lib translat` 50 项通过，调试构建已更新 tray-run 托盘；真实设置窗口、输入法与浮层位置未验。
