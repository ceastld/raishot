# 剪贴板贴图落点（v2）

## 目标

复制图片时，在同一次剪贴板写入（同一个数据项）里同时放图片格式与一条私有落点记录。其它软件只按 PNG／DIBV5／DIB 粘贴；RaiShot 的“剪贴板贴图”读到落点后把贴图放回该放的位置。

## 格式

- 剪贴板格式名 `RustShot.PinPlacement`（不带版本号），内容是 UTF-8 JSON，靠 `version` 区分字段；读不懂的版本整条忽略。
- 公共字段：`version`（当前 2）、`png_bytes` 与 `png_sha256`（把落点绑定到同一份 PNG，剪贴板管理器保留旧私有格式时不会误用）、`width`／`height`（须与 PNG 头一致）。
- `layout` 区分两种落点，坐标都是虚拟桌面物理像素：
  - `exact`：`origin` 图片左上角、`scale` 复制时的显示倍率（0 < scale ≤ 1）。截图复制写含外观留白的导出左上角、倍率 1；贴图复制写贴图当前位置与倍率。
  - `scroll`：长截图，`axis`（`vertical`／`horizontal`）与完成时的选区 `region`（左、上、宽、高）。只存原始信息，落点在贴图时现算，屏幕布局变了也按当前工作区摆。

```json
{"version":2,"png_bytes":183920,"png_sha256":"…","width":800,"height":5000,
 "layout":"scroll","axis":"vertical","region":[400,200,800,600]}
```

- 旧版 `RustShot.ScreenPosition.v1`（定长 56 字节，只有截图左上角）仍读取，当作 `exact`、倍率 1；新版只写 v2。

## 落点规则

- `exact` 倍率 1：原位、自然尺寸（截图外观已烘焙，不再加窗口阴影），整块落在所有显示器之外时退回工作区适应。
- `exact` 倍率 < 1：按原倍率打开在原处（贴图缩小显示时导出保持原图分辨率，若按 1 倍贴回会变大）。贴图导出放大显示时已按倍率放大，所以记录的倍率是 `zoom.min(1)`；输出中心对齐贴图窗口中心，裁剪、外观留白时仍落在原贴图上。
- `scroll`（`pin_model::scroll_origin`，长截图直接贴图与剪贴板再贴图共用）：
  - 倍率与普通贴图相同，适应选区中心所在显示器的工作区；
  - 滚动方向在工作区居中（贴图后常要在屏幕内滚轮缩放，居中给两头留同样空间）；
  - 另一方向对齐原选区中线：未缩小时就是原选区的 X（纵向）／Y（横向），缩小后窗口仍在原那一栏中间；
  - 最后收进工作区。
- 截图入口显式 `--at` 仍优先于剪贴板落点。

## 写入入口

- 截图复制、快捷操作复制：`copy_image_at`（原有调用不变，内部转 `exact`）。
- 贴图复制：`pin_export.rs::copy_placement`。
- 长截图 ✓／Enter 复制、贴图：`long_capture_view.rs::launch_output` 记下选区与方向，经 `long_output::deliver` 写剪贴板或直接定位。
- 长图调整窗（裁剪入口）里的复制没有带落点：裁边后与原选区的对应关系另算，暂未做。

## 验证

`cargo test --lib`：`clipboard_placement`（往返、JSON 字段名、过期 PNG／宽高不符／未来版本／倍率越界拒绝）、`clipboard_position`（v1 兼容）、`scroll_origin`（未缩小原位、缩小对齐中线、负坐标显示器、越界收回、横向）。没有修改系统剪贴板；真实复制→再贴图、多屏混合 DPI 未实测。
