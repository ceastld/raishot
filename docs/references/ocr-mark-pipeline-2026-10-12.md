# OCR 标记提示与像素管线检查

紧凑图标栏之后，截图和贴图的标记按钮在不可用时会提示需要完整文字定位和可用输入，并说明复制不要求文字定位。原快捷键、按钮资格、复制和标记业务不变；输入忙时不承诺复制立即可用。两处只有悬停文案插入，保留原 LF/CRLF，没有为文案编写镜像测试。

一项新增后台模型串接真实 CanvasSource 原图、capture_pin_output、Scene、套索裁剪、FixedInput、OcrOverlay、MarkLedger、Document 与 PNG 编解码。它使用固定识别结果，检查非零坐标选区跨预览分块边界时仍保留原始 alpha，四种文字标记的预览计划和提交输出一致，每种一次命令可撤销和重做，预览刷新不改变已持有的 OCR 输入。没有打开样本窗口、操作桌面或剪贴板。

三目的窄合前逐件核验原模型100附件和提示27附件，生产目的及相关依赖稳定，完整794输入只有预期三个文件变化：应用回执。

新增唯一模型与主库编译实际自然退出0，实际EXE清单匹配后按精确名称执行，完整794输入及EXE前后一致：模型回执。没有重复此前已正确的77项、13项或布局模型。此前原稿和静审仍保持静态证据，执行资格来自本回执。

本阶段完整794来源的全目标严格检查也已自然退出0。随后开始的UIA源改动需取得自己的相关检查，不继承这里的来源资格。

该模型不启动 ppocr 推理，不覆盖 CaptureView 的真实 Source/Down 包装、Windows 消息、GPUI、IME、英文悬停宽度、真实剪贴板或启动性能。固定794便携包在这三个后继改动前已构建；本阶段不重写那个 ZIP、不安装、不上传。
