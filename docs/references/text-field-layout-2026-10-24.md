# 单行文本框布局与内容裁剪

设置“文件名”页出现模板只显示末尾 `}`、日期格式只显示末尾 `d`，文字挤到左侧边框的现象。

`TextField` 的外框使用显式 flex 布局，让 `FieldText` 的百分比宽度按输入框内容区分配。水平滚动、鼠标命中和输入法位置继续使用同一份内容区 bounds；不改变正文、选区和编辑协议。

正文、选区高亮和光标统一裁剪到 `FieldText` 的内容区，并与祖先裁剪区域相交，避免长文本横向滚动时侵入内边距或边框。普通、紧凑水印和无框数值字段共用这一绘制路径。

增量 `cargo check --locked --bins --tests` 与 `text_field` 的四项输入状态回归已通过。设置页默认文本显示、长文本 Home/End 与点击定位尚未实窗验证。
