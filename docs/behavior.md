## 1. 组成与入口

| 组件 | 说明 |
| --- | --- |
| `raishot.exe` | 常驻主进程：托盘图标、全局热键、预装载一个待命截图进程 |
| `raishot-gpui.exe` | 截图 / 贴图 / 长截图 / 录屏 / 设置等 GPUI 界面 |
| `raishot-cli.exe` | 命令行：文件贴图／编辑、剪贴板贴图、OCR／检测、模型选择及各类 smoke |

设置、历史、贴图工作区、录屏与 OCR 缓存位于 `%LOCALAPPDATA%\RaiShot`。曾用名 RabShot／RustShot／Kirie 的旧数据目录和开机启动项在新版首次启动时自动迁移；旧版托盘仍在运行时本次沿用旧目录，退出旧版后再启动即完成迁移。设置按领域分成多个 JSON 文件（`settings.json`、`toolbar.json`、`tool-presets.json`、`selection-style.json`、`quick_actions.json`、`save.json`、`recording.json`），顶层带 `schema_version`；手改时某字段无效只让该字段回到默认，JSON 语法损坏则备份原文件后用默认。旧版的同名 `.ini` 在首次读取时自动迁移，原文件改名为 `.ini.bak` 保留。

贴图分组、列表状态、矢量文档和历史索引存于 `pin-workspace\library.sqlite3`；图片仍在 `pins\` 平铺，按创建时间命名（如 `20261018-135223.png`，截图贴图的原图为 `20261018-135223.original.png`，保存过程中可能短暂出现 `.v2`），录屏仍是原目录中的视频文件。启动完成后，后台自动导入有内容的旧 `workspace.json` 并保留备份，后续只写数据库；空目录与默认空配置不会因此建库。改名后若数据库已经迁入新目录、图片还在旧目录，会按现有记录自动补齐缺失图片，保留旧文件并避免重复恢复主动删除的图片。升级后不要同时用旧版修改工作区。锁、窗口占用标记与临时文件在隐藏的 `.runtime\`，SQLite 的 WAL／SHM 文件由引擎管理。首屏启动不等待数据库；迁移与恢复检查延后到后台，管理页也在后台加载列表。设计见[主界面数据模型](references/main-window-library-2026-10-19.md#7-数据模型)。

使用默认数据目录时，录屏历史也识别仍留在曾用品牌目录中的成片，可以正常预览、打开和删除；视频保留原位置。自定义数据目录只读取自己的录屏目录。历史索引只在文件明确不存在时清理，读取失败不会被当作删除。

命令行支持 `--pin-file "图片路径"` 直接贴图、`--edit-file "图片路径"` 直接打开图片编辑器，以及 `--pin-clipboard` 将当前图片或纯文本剪贴板贴图。两个贴图入口可加 `--at "x,y"` 指定屏幕物理像素的初始位置，支持负屏幕坐标；省略位置使用鼠标当前位置，最终窗口仍按原工作区规则保持可见。指定文件直接后台解码，不弹文件选择框，原文件保持不变。缺少路径、混用入口、重复位置、无效坐标或只有位置未指定入口时返回错误，不退回截图或剪贴板。三个程序放在同一目录，不要求外部宿主；当前源码及相关后台模型已按各自来源通过，实际窗口与后继交付另待验，见[文件参数入口](references/file-launch-2026-10-12.md)。

**媒体查看入口**：图库里选中截图或录屏即可在主窗口内查看，外部文件从图库“工具”菜单的“打开图片文件…／打开视频文件…”进入，用内置查看器打开；不需要设置环境变量。也可用 `raishot-cli --view-image [图片路径]` 或 `--view-video [视频路径 ...]`，省略路径时选择文件。视频最多128项，保留输入顺序和重复项，坏项可继续前后浏览；PgUp/PgDn切换，L选择本地SRT/WebVTT字幕，字幕不进入当前帧导出。图片支持目录前后浏览、适应窗口与原尺寸；视频支持暂停、跳转、音量、静音、倍速、循环和全屏。视频当前帧可复制（Ctrl+C）、另存PNG（Ctrl+S）、进入图片编辑（E）或贴图（P），输出取实际提交的画面帧。图片复制或进入编辑／工具时使用方向校正后的源像素或点击时的GIF完整帧，查看旋转只改变窗口显示。

图片查看器顶栏为分组图标按钮（打开与最近 · 上一张／下一张 · 适应／1:1／全屏 · 旋转、像素网格、取色 · 编辑、裁剪、OCR、贴图、图片工具 · 复制、拖出），悬停提示带快捷键；图片信息、复制路径／文件、在文件夹中显示、重命名、回收站和 SVG 栅格尺寸收在“更多”菜单。查看器支持有限SVG离线渲染，“栅格尺寸”可指定宽高后重新栅格化，保留比例并以透明背景居中；原SVG文件保持不变，失败或取消保留当前画布。外部资源、文本和不支持的效果会明确报错；后台渲染、尺寸输入及相关工作线程已过定向验证，真实界面未验。

PSD已接入有限合并图读取：仅接受RGB8、三通道不透明、Raw或PackBits压缩，显示颜色未映射及另存不保留图层的提示。含ICC、EXIF或XMP、明确声明没有真实合并图的文件及其它颜色／压缩方式会明确拒绝；仅提供合并图像素，不保留图层编辑能力。统一入口与合并图标志回归通过，真实文件窗口与另存交互未验，边界见[格式评估](references/image-format-evaluation.md)。

超出完整解码尺寸上限的静态非交错PNG可显示最长2048像素、最多400万像素的采样总览。支持缩放和平移，100%按原图坐标计算；保留同次加载来源且预算允许时，后台补出可见区域细节，等待期间仍显示总览。原图尺寸与预览栅格分别显示；此预览未做颜色管理，不用于编辑、OCR、贴图、图片处理或复制像素，暂不支持人工旋转、网格和取色。原文件操作仍单独检查文件身份；相关22项普通回归及自制36MP大图的总览／局部细节／换源GPU像素和资源退出专项已过，多DPI及任意图片边缘效果仍未验，详见[图片查看专题](references/image-animation-streams.md)。

图库“工具”菜单可打开外部图片或视频文件；“查看图片”、录屏双击／Enter及空格预览均在主窗口内弹出查看器，关闭按钮、Esc或点击遮罩返回原列表。搜索输入和输入法组合期间不触发，长按不重复打开。宽窗口录屏详情仍有初始暂停、静音的内嵌预览；弹层打开时停止详情预览。切页、隐藏或最小化主窗口会释放播放会话。只有点“用系统应用打开”才启动系统播放器；截图双击仍贴出，贴图仍恢复。命令行独立查看仍有自己的窗口和全屏；主界面弹层不控制父窗口的全屏与关闭。验证边界见[主界面专题](references/main-window-library-2026-10-19.md#10-23-媒体入口默认接入)。

工具并入图库，不再有单独的“工具”页（`--page tools` 打开图库）。在图库中单击选中，Ctrl 增减、Shift 选一段、Ctrl+A 全选；多选时卡片角标显示选择顺序，底部操作条按选区给出推荐动作：两张图对照／拼接，三张以上拼接／转 PDF／批量导出，删除对全部所选生效。“工具”菜单列出对照、拼接、转 PDF、批量导出、分割、取色与测量、识别条码、转 GIF，选区不满足时写明还差什么；点它进入选择模式，顶部横幅提示目标与已选数量，单击勾选，Enter 开始、Esc 取消并恢复原选区。工具来源直接取选中截图或图片贴图的文件，不弹文件框；分割、取色测量、条码识别后台有界读取后开窗，转 GIF 在内置播放器里选片段导出。菜单底部另有打开外部图片／视频文件和生成二维码。常规单图调整沿用编辑器或贴图。具体处理能力见[图片工具专题](references/image-tools-workflow.md)，交互设计见[工具并入图库](references/library-tools-2026-10-23.md)。

历史页的“未完成录制…”进入独立列表，手动后台扫描本机录屏库已登记的暂存会话，显示文件状态、扫描限制和错误；取消、关闭或切页会请求停止扫描。可完整验证已登记视频，并在再次核验后另存新MP4；不修复或覆盖原件，录制仍在使用、来源已变化或请求已取消时不导出。列表不提供播放或清理，过期清单暂保留；原生验证／另存及真实页面的发现／验证点击已过，另存窗口和取消竞争仍未验，见[输出生命周期](references/recording-output-lifecycle-2026-10-11.md)。

**托盘**：左键开始区域截图；右键菜单（`src/tray.rs` 的 `menu`）顶层项带图标，随主题浅色／深色：

- 区域截图（显示当前热键）；全屏截图 ▸ 当前屏幕 / 所有屏幕
- 快捷动作子菜单：识别并复制、表格复制、扫码复制／打开、复制并贴图、快速保存等；内置动作默认不绑定额外热键。
- 剪贴板贴图（图片 / 文本，显示热键）
- 贴图 ▸ 打开图片贴图…、恢复最近关闭的贴图；显示／隐藏当前分组贴图（一个切换项）、上一个／下一个贴图分组、恢复贴图交互（关闭穿透）、关闭全部贴图（可恢复）；管理贴图…（打开主界面贴图页）
- 图库、设置、帮助与快捷键（打开主界面“帮助”页）、退出

**快捷动作**：设置 ▸ 快捷键中可启用、编辑或新建动作，选择采集源、是否先编辑、最多三个固定步骤及历史策略。命令行 `raishot.exe --action ocr-copy` 走常驻待命路径；脚本可用 `raishot-cli.exe --capture --action ocr-copy`。动作 ID 未知或被禁用时返回错误。设置 ▸ 截图的“完成动作”决定 ✓、Enter 和双击的输出；Ctrl+C 固定复制图片。失败保留选区和已完成的副作用，重试从失败步骤继续；文字动作默认不写截图历史。详见[快捷动作](references/capture-quick-actions-2026-10-12.md)。

**实时窗口贴图**：框选后按 Shift+T，或在“更多操作”中选择“实时窗口贴图”。只显示源窗口画面，左键拖动、滚轮缩放、Ctrl+滚轮调透明度、中键恢复 100%；右键可前置源窗口、恢复源窗口或转为普通静态贴图。最小化或窗口丢失时显示冻结画面；正常退出尽可能抓取最后一帧保存，重启恢复为静态贴图。当前实现与未验边界见[实时窗口贴图](references/window-pin-live-2026-10-12.md)。

**表格识别与复制**：识别下拉的“表格识别”、表格页“用模型识别表格”、表格复制快捷动作和贴图“复制表格”调用独立 SLANet_plus 结构模型，文字由本机 OCR 提供；首次使用按需下载约 7.8 MB 模型并校验，之后复用本地缓存与 OCR 运行库。模型负责行列与合并跨度，复制同时写 TSV 和 HTML；单元格里的英文空格及换行保留。模型失败或漏行时保留文字与可用规则结果，并显示说明。文件入口为 `raishot-cli --table-file image.png [--ocr-profile tiny|small]`，输出单元格、TSV／HTML 和来源 JSON。

**公式识别**：识别下拉选择“公式识别”，将当前选区图片发送到设置中配置的 DeepSeek API，结果原位停靠在截图／图片编辑器内。Markdown 预览混排文字、公式和表格，局部错误保留该段源码及提示，其余内容继续显示。源码保留换行并可在本机编辑；Enter 换行、Ctrl+Enter 提交，不重复调用 API。可按顺序提取并复制 LaTeX、复制完整 Markdown 源码，或复制整份排版图片；截断、括号和可疑标签关联需先校对。完成后的 API 译文复用该组件，普通 OCR 不自动推断表格。公式与翻译不下载本地大模型，主动表格识别继续使用本地方案。边界见[API 公式与翻译](references/deepseek-formula-translation-2026-10-24.md)。

普通文字识别只按文字和段落显示，不自动推断表格、不生成表格缓存，也不显示“表格”页。需要表格时主动选择识别下拉“表格识别”，或在文字面板“更多”中选“识别为表格”；表格复制快捷动作和贴图“复制表格”同样属于主动入口。只有这些入口才识别行列和合并格、显示网格与原图描边，并复制 TSV／HTML；主动表格结果重识别仍保持表格模式。复制的 HTML 将单元格设为文本格式，保留前导零、长编号和尾零；在 Excel 求和前可显式转换为数值。

新增全局操作按“截图、贴图与分组、应用”分区。分组显隐合并成一个动作和一个绑定；显示时也会解除本组此前单独隐藏的贴图状态。原有快捷键和禁用值保留，新操作默认不占用按键。命令目录、配置兼容与验证边界见[快捷键系统](references/shortcut-system-2026-10-27.md)。

设置页每个动作一行：点击快捷键框直接录制，按下组合并全部松开才保存，录制中框内实时显示按住的键；框内 × 清除（停用），非默认时右侧 ↺ 恢复默认。录制期间拦截全部物理键盘与鼠标输入：Esc 取消、Backspace 停用、单击鼠标左／右键退出录制。字母 / 数字 / 标点必须带修饰键；鼠标左键不能作前缀，单独左／右键和不带前缀的滚轮不能作触发。只用 Ctrl/Alt/Shift/Win 作前缀的组合仍注册为系统热键（不分左右）；其余组合由托盘的输入监听匹配，只在配置了这类组合时才安装监听，前缀键按下后若没有触发会在松开或按下其它键时补发。快捷动作行用同样的快捷键框，目前只接受系统热键组合。校验错误、两个组合互相冲突、与快捷动作冲突、被其它软件占用都显示在该行说明处并保留原热键；托盘回执自动等待约 3 秒。旧配置里的 Ctrl+Alt+Shift+S / Ctrl+Alt+A / PrintScreen 预设值照常生效。设计见[全局触发器](references/global-triggers-2026-10-22.md)。

**设置分类**：常规（语言 `system|zh-CN|en`、主题 `light|dark|system`、开机启动等）、截图、贴图、翻译、快捷键、保存、工具栏（绘制工具显示 / 隐藏 / 排序，截图与贴图共用）。托盘右键菜单同样随主题显示浅色／深色（Windows 10 1903 及以上）。

设置窗口只保留一个，默认不置顶：从托盘或截图界面重复打开时，激活已有窗口；已最小化则还原，保留当前分类和未应用的修改。关闭后可重新打开。

设置窗口即 RaiShot 主界面：侧栏上半“贴图”“图库”，下方是设置分类，底部“帮助”按节列出常用操作与当前快捷键。贴图页见 2.5 末尾，历史页见 2.8。保存页与翻译服务的输入类设置改动后，页面底部才出现“取消修改／应用”条；其它设置即时保存。命令行 `raishot-gpui --settings --page pins|history|settings|help` 打开指定页，窗口已开时切到该页；旧的 `--history` 打开图库，`--page tools` 同样打开图库。

翻译页的“译成”下拉选中即保存，支持自动判断、14 种常用语言及自填语言。翻译服务默认 DeepSeek，填写 API Key 后点击“应用”；密钥以 Windows 当前用户加密保存，输入框默认遮蔽。也可选择自定义兼容接口或关闭服务。翻译优先使用已配置 API，代码、公式、网址、占位符和数值在本机保护；表格只翻译单元格文字，行列、空格及合并关系不交给模型重建，复制结构化译文同时保留 TSV／HTML。图片翻译默认本机 OCR 加文本 API；遇到表格转到结构化译文页，显式选择百度图片引擎时沿用该引擎。更改接口或密钥先进草稿，“应用”只保存配置，不发送请求。详细边界见[API 公式与翻译](references/deepseek-formula-translation-2026-10-24.md)。

设置内容延伸到标题栏，品牌与导航共用顶部布局；顶部空白和品牌区可拖动，双击可最大化／还原，右上角保留最小化、最大化／还原、关闭按钮。标题栏随主题和语言更新；窗口顶边可调整大小，表单输入法候选不会阻断窗口操作。

## 2. 功能总览

### 2.1 截图

工具字母只响应裸键，Shift+E保留对象橡皮擦；未定义的修饰组合不会变成截图工具或输出命令。普通截图Enter要求无修饰键，文字输入器仍按自己的Enter合同处理，见[宿主快捷键阶段](references/host-shortcut-modifiers-2026-10-12.md)。

- 冻结所有屏幕，跨屏框选；负坐标、高 DPI、旋转屏均按虚拟桌面物理像素处理。
- 多屏分别采集，不保证动态画面来自完全相同的时刻。截图界面使用覆盖虚拟桌面的单个 GPUI 窗口，控件按该窗口统一的 DPI 倍率显示，混合 DPI 暂不逐屏独立缩放；虚拟桌面任一边超过 16384 物理像素时会拒绝截图并提示调整屏幕布局。
- HDR 屏：截图、长截图、录屏都按该屏的“SDR 内容亮度”换回 sRGB，普通窗口与关闭 HDR 时颜色一致，不再过曝发白；比 SDR 白更亮的 HDR 高光截断为白。见[HDR 截图](references/hdr-capture-2026-10-19.md)。
- 首屏冻结前，DXGI 遇到可恢复的设备／访问丢失时最多重建一次；使用同一取消请求。已冻结图像读回失败时保留真实错误并结束，避免重截变化后的桌面。相关后台模型已通过，实际驱动故障仍待验。
- 快速框选窗口未取得焦点时，沿用同次冻结图继续打开编辑界面，并重新核验实际焦点；设备 DC 的格式或坐标映射不支持时可切换 DXGI 采集。截图异常的具体错误、崩溃回溯和进程退出码记录在数据目录的 `diagnostics` 中，不含截图像素，见[截图会话异常恢复](references/capture-session-failure-2026-10-21.md)。
- 框选前：每次移入或返回窗口都立即显示该窗口范围，UIA 查到完整元素后直接细化（取鼠标处最深的元素；停在容器空白处时即为该容器，完整查询只有窗口时也自动显示）。同窗口等待新结果时保留旧细框最多 1 秒，超时恢复窗口；跨窗口立即切换，不需滚轮恢复。窗口选区贴合可见边缘，排除透明调整边框。窗口仍参与滚轮层级切换，细化前已滚轮选中的窗口层也会保留；滚轮切换有短过渡，鼠标跟随直接切换。穿过元素空隙的旧点大范围需确认后才放大；点击不采用被隐藏的窗口兜底；放大镜显示颜色与坐标；Alt 临时辅助线；反引号切换是否包含鼠标指针。
- Ctrl+A（或 Ctrl+Shift+A）固定预览：在所在显示器与整个虚拟桌面之间切换。
- 选区：移动、八向缩放、方向键微调、滚轮扩缩；左上角尺寸条可输入全局 X/Y/W/H，允许负坐标，越界输入有提示，不移动标注或清除重做栈。
- 尺寸条为“W × H ⌄ │ [原样][圆角][卡片][描边][窗口] 调整 │ 刷新 ⋯”（刷新只在截图时出现，同 F5）：五个样式缩略图单击即换，指针停在缩略图上时选区先预览该样式、移开恢复，在样式组上滚轮逐个切换（到头不循环）。每个样式记住自己的圆角／阴影／边框参数并跨截图保留，缩略图按记住的外观绘制，下次截图沿用上次选的样式。“调整”只打开当前样式的参数：圆角、阴影扩散、边框粗细拖到 0 即关闭，阴影开着时显示浓度与颜色，边框开着时显示内外侧与颜色，底部为导出尺寸与“恢复默认”；原样没有参数。空间紧张时样式组收成“当前样式 ⌄”单按钮，点开是画廊（五个大缩略图＋当前样式的调整项），更多菜单的“选区外观”也打开画廊。圆角开启时选区框和自动选区悬停框都沿圆角绘制，框内即导出的圆角图；指针进入选区时四角一起浮现白底蓝边的菱形圆角控制点（光标为该角方向的对角箭头），悬停时旁边显示当前圆角，沿对角线拖动即调半径，拖动中四段圆弧加亮、缩放点暂隐，拖到 0 即关闭圆角；在原样上拖出圆角会切到“圆角”样式。坐标和导出尺寸在悬停提示与面板里；文件编辑以原样开始。面板优先放在选区外（条外侧 → 选区左 → 选区右），打开面板不切换当前标注工具。全屏或贴边时尺寸条转到屏内可用位置，OCR 面板打开仍可使用。
- 已选区显示实际样式边框时，蓝色选区轮廓和拖圆角时的弧线高亮会隐藏，便于看清贴图后的边框；缩放点、圆角控制点、数值提示与拖动命中保留。关闭边框、粗细为 0 或边框全透明时显示定位轮廓。
- 选区内容和边框共用一个圆角参数：设为 0 时都为直角，开启时内容一起裁圆，边框沿同一轮廓向内或向外延伸；截图预览、导出和贴图保持一致。
- 自定义颜色（属性栏色块末格的色环、文字描边／底色细项的自定义色块、选区阴影／边框颜色）在画布内以浮层打开，跟随主题：拖动饱和度明度区与色相条、点预设或输入 HEX，Enter／“确定”应用（一次撤销），Esc／“取消”回到原面板；单击原色／新色对比条的左半可恢复原色。
- 刷新与“⋯ 更多”只保留在上方选区条，截图主工具栏不再重复显示；更多菜单提供绘制工具与其它操作，弹窗跟随上方入口。刷新按钮 / F5 更新冻结底图并保留选区、标注、撤销/重做、外观与工具栏位置；失败保留原编辑，刷新中裸 Esc 取消本次刷新。重选是独立入口，只清选区并保留标注。输入、绘制、套索或交接未结束时先完成当前操作。
- 工具栏拖回默认停靠位附近会显示吸附预览，松手恢复跟随；双击把手或更多菜单“工具栏跟随选区”也可回位。手动摆放可跨屏，移动选区不强制搬动手动工具栏。
- 跨屏框选时工具栏与结果面板锚定结束点所在显示器；结束点那块屏只沾到选区一条窄边（不到选区宽或高的 15%）时，改放到与选区重叠最多的显示器。
- 主工具栏固定区按用途分组：撤销／重做／更多／刷新 ｜ 长截图／录屏 ｜ 识别（带下拉：文字识别 R、识别并翻译 T、表格识别、图片翻译 Y、二维码识别；主按钮执行本次会话最近用的一项）｜ 贴图／保存／取消 ✕／完成 ✓（完成在最右端）。贴图宿主的下拉只列文字与二维码识别。主栏分组按钮（识别、各工具组）的下拉优先贴着主栏朝选区一侧展开，不盖二级属性栏；那一侧放不下时放到二级属性栏外侧，仍放不下才覆盖二级属性栏；当前工具没有二级属性栏时朝远离选区一侧展开。
- 套索：手绘闭合轮廓，边界外透明输出。
- 画布覆盖整个虚拟桌面，选区只决定遮罩与输出裁剪，移动 / 重选不影响标注。
- 复制或保存主输出成功后，历史／最近目录记录失败只提示，不阻止完成；主输出失败继续保留截图。配置损坏先保留原文件备份，读取失败的临时默认设置不会覆盖原配置。

首次框选的工具栏已减少准备等待：冻结首屏就绪后并行准备编辑界面，新版直接加载预编译着色器。后台编译成本与交付检查已记录，真实首显时间待自然使用确认，见[延迟修复](references/toolbar-selection-latency-2026-10-12.md)。

### 2.4 识别

- 普通 OCR 的选字高亮在原图笔画证据充分时收紧上下与整行首尾留白；首尾只裁外沿，保留内部字间分界。原图明确支持水平时纠正轻斜显示框，保留分字停点的横向位置与原始 OCR 行框；背景复杂、文字很淡、边界不完整或方向不明确时保留原投影。原理与样例见 [OCR 选字框与段落说明](references/ocr-boxes-and-paragraphs-2026-10-24.md)。

- 截图与图片编辑器的普通文字识别中，选字与整行多选并存：在文字上拖动是逐字选取（列表单击选中该行文字、双击复制并关闭）；从空白处拖框选中相交的整行，Ctrl／Shift 追加，Alt 减选，列表行 Ctrl 点击切换、Alt 点击移出。Delete 排除所选（选字时按涉及的整行），并以一个局部填充标注用四周底色抹去原图上这些行（缺少可靠定位的行只排除、不抹去，提示中注明行数）；“已过滤”逐项恢复时从填充中移除对应行，全部恢复则删除填充；Ctrl+Z 一次同时撤销排除与填充。复制按原始行顺序排列，不带入未选行。筛选入口收在底栏图标按钮中，点击展开自动过滤开关、排除／撤销与已过滤项恢复，平时不显示数量和操作提示；展开保留当前页签与选择，Esc、点外或切页收起。自动过滤默认关闭，启用时按钮使用强调色，只隐藏、不改原图。导出与复制图片按所见输出抹去后的像素。标记（H/U/W/D）仍作用于选字，表格／译文的独立输出保持。
- 普通 OCR 默认进程内 `ppocr`（CPU）。设置 ▸ 截图 ▸ 文字识别 ▸ 模型可选“Tiny · 轻量”或“Small · 标准”，默认 Tiny；Tiny 识别不理想时可切到 Small 尝试，保存后提示下一次识别生效。所选模型首次从固定官方来源后台下载，按清单大小与 SHA-256 校验，只加载使用的档位。切换用于下一次请求，已经提交的全文／局部重识别、控件文字补救保留原档位；Small 失败直接提示，不自动切回 Tiny。智能马赛克的检测同样使用所选档位，重新激活或新请求时清除不匹配的旧候选。
- 同一处“预热”：截图时（默认，截图待命进程在后台提前加载已缓存的模型）／始终（贴图窗口所在进程也在首显约 1 秒后加载，多占内存）／关闭（首次识别时再加载，稍慢）。下一次待命或贴图进程启动时生效。加载时跳过 ONNX Runtime 用不上的 SetupAPI 设备枚举，冷加载从 4–7 秒降到约 0.3 秒。预热、冷加载、等锁或耗时 ≥1.5 秒的识别把各阶段毫秒数记到 `%LOCALAPPDATA%\RaiShot\diagnostics\ocr-timing.jsonl`（最多 200 行，不含图像或文字）。
- 文件 CLI 可用 `--ocr-file input.png --ocr-profile small` 或 `--detect-text-file input.png --ocr-profile small`；省略档位固定 Tiny，不读取界面设置。显式档位仅用于 `ppocr` 的文件识别／检测，Windows 提供者和自测不接受该参数。仍可选 Windows OCR；准备依赖时取消请求会停止后续锁等待、读取、校验和解压，并清理自己的暂存文件；单次同步 I/O 返回前可能稍后生效，已经提交的有效缓存保留。
- 截图 OCR 识别期间在实际选区内显示淡色扫描光带和“识别中”提示；局部重识别只覆盖对应文字行。完成、取消或来源失效后停止，动效不进入复制、保存或标注像素。
- 全屏 OCR 完成后可点击结果面板底栏的“敏感文字”，逐项检查邮箱、电话和身份证候选。默认全部未选；上下／Home／End 导航，Space 勾选活动项，Ctrl+A 全选，Esc 取消预览，方向键可长按。勾选后明确确认马赛克或模糊，多个区域共用一个标注、一次撤销。没有可靠定位的文字不列为可处理候选；取消、空选择或正文／图像来源改变不改图。候选预览不进入导出，成功处理后旧 OCR 定位关闭。基础、键盘及主题保护限定模型已按各自来源实际通过，真实交互待验。
- 贴图已有 OCR 时，右下角“敏感文字”可打开同类候选，默认不勾选；确认马赛克／模糊后整批一次撤销，Esc 或取消保持原图。预览与查找、局部重识别面板互斥；有选字时入口避开最底行的“重识别此行”。来源、处理、历史或主题变化使旧确认失效，切回同主题也不能复用旧按下。源码及21项相关后台模型已按762来源通过，真实窗口待验。
- 贴图 OCR 同样显示实际识别输入范围，局部重识别只显示对应行；范围随图片缩放和视口投影，扫描层不拦截鼠标、不夺焦点，也不进入导出。当前已接入源码，真实窗口动效待验。
- 全屏 OCR 的“复制表格”绑定按下时的结果；按住期间替换识别结果、切换全文模式或改动正文后，松手不会复制另一份表格。表格算法及复制失败后保留结果的行为保持。
- 待命截图进程在完整固定缓存已存在时后台准备 CPU OCR 引擎，不保留截图像素；缺少缓存仍按原入口首次下载。推理线程由程序自动使用 4 个，可用处理器不足时降为 2 或 1，不新增用户选择项。
- ppocr 对同一位置、同一原文且阅读方向与投影高度一致的重复识别行保守去重；相邻行、异位同文与不确定几何保留。词框仍为估算。
- 结果以“原位文字层”显示在截图上：可拖选、复制、对文字加高亮 / 下划线 / 波浪线 / 删除线标记。 截图和贴图的持久标记要求所有选中非空白字素有可信定位，缺少部分定位时整次拒绝，原文仍可复制；空白不要求定位，不能只标一部分却提示成功。源码与相关验证见 [来源和标记阶段](references/ocr-source-and-marking-2026-10-11.md)。
- 框选前按 R 或 Shift+C 识别悬停区域 / 控件文字（UIA 优先）。同一控件的 TextPattern 不支持或合法返回空白时，继续读取 ValuePattern；有效正文保留原始空格和换行。超时、提供者错误或 UTF-16 正文超限仍返回错误，不借控件名称替代正文。此回退已接入代码，真实控件提供者与界面交互待验。
- 二维码自动识别（纯 Rust，`capture_qr.rs`）：选区稳定约 140ms 后在后台读取选区原始像素（不含标注）识别，每个码中心显示圆形悬浮按钮；鼠标悬停即弹出操作（复制内容／链接、在浏览器中打开、在结果面板中查看），移开约 0.3 秒自动收起，单击按钮固定弹层、再单击收起；双击按钮直接打开链接（仅 http(s) 与 www. 开头，打开后结束截图）；文本码双击只固定弹层，不隐式复制。弹层优先放在按钮右侧，靠屏幕右缘时改放左侧或上下方，不会盖住按钮。一张图内的码数量不设上限，支持深底浅码、低对比与深浅背景混排，识别方法见 [二维码多码识别](references/qr-multi-detect-2026-10-12.md)。调整选区即作废重扫；选择绘制工具、拖动或显示识别结果时隐藏按钮，Esc 先收起弹层。识别按钮不再带二维码下拉，“更多操作”中的“二维码识别”保留为手动入口（含标注合成，同一识别方法）。`raishot-gpui --qr-smoke` 以生产图片编辑入口实测了自动识别（设选区后约 170–200ms，含 140ms 稳定等待）、按钮落在码中心、悬停展开与移开收起、单击固定／再次点击收起／Esc 收起、文本码“在结果面板中查看”和选区移开后作废；复制（会写剪贴板）、双击及打开浏览器、托盘触发的真实截图层未自动点击。
- 纯文本翻译（`translate.rs`）：原位结果面板的“译文”页（点开即按段落翻译全文，逐段原文／译文对照，悬停高亮原图段落）、选字浮条的翻译按钮或“更多”菜单的“翻译所选／翻译全文”（结果都在“译文”页），识别下拉的“识别并翻译”，或全文结果面板的“翻译”（有选择时译所选，否则译全文）。译文流式显示：边收边出，“译文”页已收到的段落先逐段对照，末尾提示仍在翻译；译文页页签行右侧的“对照”按钮可隐藏每段上方的原文，设置写入 `settings.json` 的 `translation_show_source` 并跨会话记住；服务端不支持流式时整段显示。只在点击时把文字发往 OpenAI 兼容接口，默认 `https://index-translate.bilibili.com/v1`、模型 `Index-Translate-35B-A3B`，无需密钥；不发送图片或剪贴板。第一次使用内置服务时在屏幕上提示一次上述发送范围（记入 `translation_notice_shown`）。目标语言 `auto`：以汉字为主译为英语，其余译为简体中文。原位层的译文在面板“译文”页，底栏主按钮为“复制译文”；全文结果面板的译文仍显示在正文下方；正文编辑、撤销／重做或输入法取消使旧译文失效，改回相同文字也不会恢复；仅选择变化保留。新结果或返回截图清除译文，旧回执与旧按下不能覆盖或复制新译文。设置 ▸ 翻译首屏下拉选目标语言，端点与模型在“高级”里，也保留 `settings.json` 的 `translate_endpoint`（留空关闭翻译）、`translate_model`、`translate_target`（`auto`／`zh-CN`／`en`／`ja`…）；真实 GUI 交互待验。
- 图片翻译（`image_translate.rs` 核心、`capture_image_translate.rs` 接入）：截图主工具栏识别下拉的“图片翻译”、“更多操作”的“图片翻译 · Y”、按 Y，或原位结果面板“更多”的“翻译图片”。已有原位 OCR 结果时直接使用，否则先识别再翻译。按段落视图的划分逐块请求同一翻译接口（并发 3），只发送块文字；网址／路径／代码、纯数字、倾斜或竖排文字，以及已是明确目标语言的段落跳过。底色取原文行框外 1–3px 环带的中位色，文字色取框内与底色差异最大的像素均值；译文从原行高推算字号、逐级缩小至放下，最小 9px 仍放不下时向下延伸。全部返回后退出原位文字层，把每段译文作为带不透明底色的普通文字标注一次插入（一次 Ctrl+Z 撤销），可双击修改，复制／保存／贴图按所见导出。翻译中状态栏显示进度，Esc 退出文字层即取消；截图范围在完成前改变则放弃结果。会话内按目标语言与原文缓存译文，不写磁盘。贴图与图片编辑入口、翻译面板和对比视图见 [图片翻译阶段](references/image-translate-2026-10-12.md)，真实界面交互待验。
- 百度图片翻译 V2：设置 ▸ 翻译 填写百度 APP ID 与 API Key 后（引擎“自动”或“百度 V2”），同一入口改为上传选区图片到百度，返回的擦除重绘贴合图在图片编辑窗口打开，截图随之结束；选“本机排版”仍走上面的自研流程。

### 2.5 贴图

截图复制会附带导出图在虚拟桌面中的物理位置（含圆角／阴影／外边框留白），再次从剪贴板贴图时按原位置和原尺寸显示；贴图复制附带贴图当前位置与缩放，再贴图回到原处、原大小；长截图复制附带选区与方向，再贴图与长截图直接贴图位置相同（纵向长图横向保持选区位置，缩小时对齐选区中线，纵向在屏幕居中；横向长图反之）。位置只对同一份图片有效，格式见[剪贴板贴图落点](references/clipboard-pin-placement-2026-10-21.md)。显式 `--at` 优先，原显示器移除而位置完全不可见时自动放回可见区域。普通 PNG 图片的透明及半透明像素直接透出桌面，进入标注或缩放后仍保留透明；不按背景颜色抠图，图片编辑器继续用棋盘表示透明区域。

贴图滚轮默认以鼠标位置为中心，连续滚动保持同一原图点；设置及右键菜单仍可改为图片左上角或图片中心，已有明确偏好保留。缩放先备好新画面，再调整窗口并立即绘制首帧。普通滚轮按 10% 一档（10%–500%），Shift+滚轮按 1% 精细缩放；拖边、适应屏幕或精细调整后的非整档倍率，普通滚轮先沿滚动方向对齐到相邻 10% 刻度。Ctrl+滚轮调不透明度 10% 一档，Ctrl+Shift+滚轮 1% 一档。标注工具占用滚轮时用 Alt（＋Shift）滚轮缩放贴图。

置顶浮窗显示图片；剪贴板文本生成的文字贴图是矢量文档，不生成底图位图，纯色底和默认文字色实时跟随浅色／深色主题，可直接在其上标注，复制、保存、拖出时才按当前主题渲染成图片（旋转等图像处理会先渲染成普通贴图）。缩放、透明度、置顶、锁定、鼠标穿透、缩略收纳、旋转翻转、灰度反色亮度、阴影；空格呼出与截图共用的标注工具栏（与截图一致贴贴图右下方、右缘对齐，下方放不下时移到上方）；OCR 选字、取色、二维码；Ctrl 拖出 PNG、拖入图片新建贴图；关闭可恢复；贴图工作区管理分组与标题。选中 OCR 文字后可在菜单选择段落复制，或按 Ctrl+Alt+C；按识别行在图中的位置合并同一段内的折行（中文直接相连，英文补空格），原文复制和文字选择范围保持。

截图生成的贴图把原始内容、可编辑文档和圆角／边框／阴影分别保存。边框保留截图预览选择的内侧或外侧位置，缩放、复制、保存及恢复沿用同一设置；内侧边框不额外扩展内容尺寸，外侧边框向外延展。外观不压进底图，选字、标记、裁剪、旋转和缩放都按内容坐标操作；输出时再共同合成外观。工作区及关闭恢复保留原始内容、当前图像处理、可编辑标注、外观和窗口尺寸，图像处理不重复应用。窗口尺寸超出可见预览预算时自动缩小并显示状态；调整失败仍允许按原编辑收尾流程隐藏或关闭。真实混合DPI、首显和恢复交互待自然使用验证。

普通图片贴图及带截图外观的图片贴图关闭、恢复后保留标注文档的真实撤销／重做历史、对象 ID 和组关系，双栈合计最多 128 条；容量不足时裁最远历史，保留当前内容。旧记录没有历史时恢复内容并使用空历史，不制造整批插入的撤销。保存失败保留窗口和原记录；已有 20 条关闭记录时按保留政策清理最旧记录后保存。源码与相关后台模型已通过，真实关闭恢复待验。

截图转贴图现交接完整可编辑文档、真实撤销/重做两栈及共享CPU采样域，既有标注不烘进底图；预览由GPUI整组内容合成统一应用圆角和套索，边框与阴影仍独立绘制。可见输出范围与完整采样域分别保存；复制、保存和拖出不会带出选区外像素。副本、关闭恢复与工作区按内部来源归档保留完整文档和上下文，普通导出不包含该私有来源。源码、相关模型与固定来源严格检查已通过，实际GPU、首显、多屏和恢复交互待自然使用。图像处理边界的非破坏节点及跨处理恢复仍未接完，见[矢量文档后继](references/pin-vector-document-next-2026-10-12.md)。

矢量文字贴图的关闭恢复、工作区和“再贴一张”保留文字与其它标注、对象和组身份、真实撤销／重做两栈；删除全部对象后仍能重做。纯文字继续使用兼容V1格式，混合文字与标注使用V2，主题只映射默认文字色，普通标记RGB保持；命名字体按显示环境恢复。不支持的裁剪／蒙版或载荷明确拒绝保存并保留窗口，不丢弃标注。双栈最多128步，保存前完整校验再按容量裁旧历史。后台相关模型已通过，真实窗口、字体显示和导出像素仍待验，见[混合文字历史阶段](references/pin-mixed-text-history-2026-10-11.md)。普通图片的六项图像处理参数及真实两栈也已接入保存／恢复、工作区和副本，最多64步，相关后台PNG模型已通过；混合底图／裁剪／烘焙检查点仍未持久化，见[图像处理历史阶段](references/pin-processing-history-2026-10-11.md)。

操作反馈以左上角气泡显示，淡入后到期前淡出自动隐藏：缩放倍率与窗口像素尺寸（如“125% · 1600×900”，含拖边）、不透明度、锁定／解锁、置顶、旋转翻转等图像处理约 1.5 秒；复制结果、错误等状态消息约 4 秒，后到的一条覆盖先到的。滚轮到达缩放或不透明度上下限、锁定时滚轮也会提示。气泡不接收鼠标，指针、OCR 查找栏或敏感信息面板占着左上角时改到左下角；首显、恢复等非操作变化不提示。右上角操作按钮仅在鼠标悬浮该角落时显示，左下角倍率／锁定信息仅在悬浮左下角时显示（同时回看最近一条状态消息）；绘制、移动、缩放、选字和取色期间隐藏，小贴图使用右键菜单及快捷键。状态消息在实际拖绘时让出图片，拖边缩放的倍率反馈照常跟随。连续笔迹只更新画布，工具与属性控件按实际状态变化刷新；圆角主体的多个裁剪区域复用同帧矢量路径，未被笔迹影响的圆角图块继续复用，触角或采样效果变化时按实际区域重绘。真实绘制延迟与悬浮观感仍待自然使用验证。

贴图可视标题：工具栏收起时按 F2 或右键“设置标题…”，在图片靠标题一侧弹出单行输入框（输入法优先），Enter 确认、Esc 放弃，点到别处或切换窗口也确认；留空不显示。标题显示在图片外的标题条，默认下方居中，设置“贴图 → 贴图标题”可改为上方，靠屏幕边放不下时自动换边；配色随浅色／深色主题，透明度与贴图一致（含穿透降透明），缩放、缩略后跟随窗口，工具栏展开时隐藏。标题条不改变贴图窗口尺寸与图片位置，不进入复制、保存、拖出、OCR，也不进入桌面截图和录屏，鼠标穿过它。标题与贴图工作区的标题是同一字段，两边改动互相同步，关闭恢复保留；新贴图的默认标题“贴图”视为未设置。见[贴图可视标题](references/pin-title-2026-10-19.md)。

贴图识别菜单提供“复制表格”：将完整可信短矩阵复制为 TSV，保留零、前导零、引号及原文；表格证据不足或来源失效时禁用，普通复制和快捷键保持。

表格可来自分别识别的单元格，也可来自每个识别行中的多个词框；支持可信的“项目＋数量”两列及纯数值矩阵。至少三完整数据行，并核列间空隙、对齐与完整来源；只在显式复制表格时生成 TSV，不自动重排普通正文。几何与正文同构的数字清单和表格无法作语义区分。

贴图 OCR 自动、选字、全文和段落复制在实际发布成功后提示成功；发布失败保留当前结果、选择、定位和标记，可直接重试。全文空白结果不清空剪贴板；有效文字选择即使只含空格或换行也原样复制。当前改动的真实剪贴板故障及窗口交互待自然使用验证。

主界面贴图页管理贴图（托盘“管理贴图…”、贴图右键“贴图工作区”都打开这里）：上方显示器布局图按真实比例画出各显示器和当前分组的贴图，单击在屏幕上标出该贴图（置前并显示“在这里”气泡），拖动即移动真实贴图，半透明为已隐藏；与显示器相交不到五分之一的贴图在图边列为“在屏幕外”，可一键调回主屏中央。分组页签单击即切换屏幕上显示的分组，双击改名，拖动页签排序，把列表里的贴图拖到页签上即移组；“＋”新建分组，空分组可删除。列表每行有显示／隐藏、锁定、鼠标穿透三个开关和“标出”“关闭”，状态实时反映、可来回切换；双击或 F2 原地改标题（Enter 确认、Esc 取消）。未打开的贴图可单张或整组打开（不受启动恢复设置限制，图像缺失的除外）。底部“最近关闭”单击即恢复，含标注与撤销记录，更多在历史页；右侧“启动时恢复”开关决定托盘启动时是否重新打开上次屏幕上的贴图。锁定、穿透与标出经单张控制通道交由贴图窗口执行并回执，贴图忙碌或关闭中时开关置灰。

贴图页可按标题或窗口尺寸搜索当前分组列表（忽略大小写，尺寸如 `1920x1080`）；Ctrl+F 聚焦搜索，Esc 先清空查询。布局图、分组计数和最近关闭不受搜索影响。

关闭贴图的恢复记录默认启用，与截图历史分开；最多保留最近 20 张、合计 128 MiB、7 天，超过数量、容量或期限时清理旧记录，可在设置中关闭。

### 2.6 长截图

建议每次滚动不超过约半屏，让相邻画面保留足够重叠；这是操作建议，不是固定的匹配阈值。重复或动态内容难以匹配时，减小滚动幅度并等待画面稳定。

框选后按 L 或点工具栏按钮；手动滚动或自动滚动采集，纵 / 横向拼接、去重、固定页眉页脚；采集中选区外侧（竖向在右、横向在下）的实时预览与选区中线对齐，从中间向两侧展开；预览按固定比例缓存缩略线，只渲染新拼接的内容并按显示帧率发布，拼接结果逐行出现；采集中按住“移动选区”沿滚动方向拖动时采集不停：框跟手移动（限所在显示器内），拼接把框的移动当作滚动，右侧预览实时增长，Esc 回到原位；暂停后可自由移动或调整尺寸，松开后验证新区域并继续拼接。操作条全部为图标：拖动柄、移动选区、暂停 / 继续、自动滚动、撤销、设置（方向、固定栏、重新采集）｜裁剪、保存、贴图｜完成复制、取消。下方保留一条薄提示行显示状态、尺寸、错误或生成进度，长提示可悬停看全文；自动滚动从慢开始，依据每次拼接的匹配质量与页面响应自适应调速：连续可靠时逐步加快，匹配变差或响应变慢时降速，持续无法匹配或到达页面边界时停止并保留结果。

完成复制（Enter / Ctrl+C）直接复制长图并结束；裁剪打开同窗长图编辑器，剪辑与现有标注共用画布和撤销。沿截图方向拖选删除或仅保留，图片外缘拖动裁四边；标注工具下也可从剪辑轨选段。删除保留原图与标注，接缝可预览、展开调整或恢复；剪辑面板可输入四边裁去像素并管理记录。等比可读总览与全长标尺负责定位，复制／保存／贴图均按剪辑成品输出。“继续采集”返回原面板。原图超过 3200 万像素或单边 65535 时暂用旧调整窗；成品超限会阻止输出。采集面板的保存、贴图仍直接输出，生成期间显示“正在生成长图…”，取消保存或失败保留重试流程。源码已接入，真实界面验证进度与大图边界见[长截图完成流程](references/long-editor-redesign-2026-10-20.md)。

拼接前复核共有正文中的接缝，局部动态内容影响原接缝时寻找可信行；没有可靠接缝时保留最后成功帧，继续采集可重试。后台算法、拒绝恢复和撤销像素已验证，实际网页滚动待验，见[动态接缝阶段](references/long-capture-dynamic-seam-2026-10-12.md)。

### 2.7 录屏

框选后按 G 或点录屏按钮；Media Foundation 编码 MP4（H.264 + AAC）或转 GIF；延迟开始、帧率、系统声 / 麦克风、按键与点击显示、暂停；停止后原位预览，可转 GIF、保存、复制文件、重录。

新配置默认 30 FPS，可选 5／16／24／30／60 FPS；开始延迟默认 0 秒，可选 0／1／2／3／5／10 秒，已有录屏设置继续沿用。GIF 不带音轨。启用按键显示时，带 Windows 标准密码样式的输入框内不显示按键内容；这一保护不保证覆盖自绘或网页密码框。

结果栏在预览加载期间显示“正在打开预览”；预览失败时显示“预览不可用”，保留成片的保存／复制入口，禁用播放、跳转和倍速，可点“重试预览”重新打开。Dev运行版已包含，独立实窗的缺文件失败、重试恢复、播放／倍速／跳转及关闭资源检查通过；自有素材Done／重录的删除与身份替换保护也通过四场景实窗检查。保存／复制、实际开始新录制和物理键盘操作另待验，见[输出生命周期](references/recording-output-lifecycle-2026-10-11.md)。

音视频都以暂停或停止操作的发出时刻为界，编码或收尾等待不会延长录像；即使很快暂停再继续，也会扣除暂停区间。暂停前缺失的尾音补静音，不会用暂停期间或恢复后的声音补齐。

实验高级画质请求新增“质量／速度权衡”：可继承或设置0–100整数，显式0与继承分别保留；输入错误保留原文。此项是编码请求，实际采用情况看编码回执，不保证画质收益。相关模型与合成编码往返通过，面板真实交互未验。

实验 MP4 高级面板可成对设置输出宽高，须为正偶数且任一轴均不超过裁边后的有效源范围，编码参数按输出目标尺寸计算。普通录前格式提示和拖拽尺寸标签也显示奇数选区裁边后的有效源范围，选区与标注原点保持不变。采集和标注仍以所选源区域为准；真实面板和缩放录制尚未验证。

开始录制前可像拖窗口边框一样调整录制区域：四条边与四角内缘是不可见的拖动区，悬停换成缩放光标，不显示缩放点。原位预览按视频物理像素 1:1 绘制，不随布局取整缩放；拖动预览画面可移动整个结果窗口（边框与工具栏跟随，点击仍是播放／暂停，重录用移动后的位置）。

工具栏按内容定宽：设置组（延迟、帧率、格式、声音、按键显示）｜录制、暂停、标注、显示／隐藏标注｜关闭。按钮说明是贴着按钮的小气泡（首次悬停 0.6 秒、录制中 1 秒，之后移到相邻按钮立即显示），出在工具栏外侧，不改变工具栏大小、不进录像；不可用的按钮和下拉打开时不出，点一下即收起。消息单独显示在工具栏外侧：进度约 4 秒，警告琥珀色约 6 秒（指针停留时暂停），错误红色、点一下或下一次操作时收起；复制、保存、转 GIF 成功时按钮短暂变成对勾，详情放进该按钮的说明。拖动选区边时左上角显示尺寸。延迟、帧率、格式、倍速下拉按内容收窄并对齐所点按钮。见[录屏工具栏提示](references/recording-toolbar-tips-2026-10-20.md)。

按键与点击显示（设置组的“按键显示”下拉）在录制时直接合成进视频帧，停止即得成片，不二次编码：左键蓝、右键琥珀、中键紫的光圈在按下时跟随指针（拖动时也在），松开后从松开处外扩淡出；滚轮为指针右下的深色小胶囊，箭头指向滚动方向，连续滚动只保留一个；按键以键帽显示，默认在左下角，下拉里的“按键位置”可改为左上、右上、底部居中或右下（Ctrl、Shift、S 各一枚，1 秒内重复显示 ×N），最新一行贴所选边缘、旧行向内堆叠并减淡，整行淡入淡出。开启点击显示后，录制期间屏幕上同步显示同款光圈和滚轮胶囊（只限选区内，排除采集、鼠标穿透），倒计时、暂停和远程画面兼容模式下不显示。见[录屏输入显示](references/recording-input-display-2026-10-23.md)。

录制/暂停期间点“标注”，在工具栏外侧展开标注工具栏：编辑、矩形、箭头、画笔、荧光笔｜颜色和粗细（色块、粗细、透明度点一下即生效，选中对象时可撤销）｜撤销、重做、删除选中、清空｜完成；再点“标注”、点完成或按 Esc 收起。眼睛按钮隐藏／显示已画标注，隐藏时屏幕和录像都不画，开始新的一笔或撤销、重做时自动恢复。Ctrl+Z撤销，Ctrl+Y或Ctrl+Shift+Z重做，Delete/Backspace删除选中，Shift+Delete可撤销清空。收起标注后继续操作其它应用，已提交标注仍进入录像。绘图层仅在启用时接收鼠标，固定录制区域；坐标和标注状态由预览/编码共享，不变的矢量图层复用缓存。当前源码及相关后台模型已通过，实际窗口/媒体/输入仍待自然使用；后继尚不在此前基础便携包，见[录制绘图阶段](references/recording-live-drawing-2026-10-12.md)。

点开始后桌面复制与音频设备并行初始化（多个音频来源也并行），就绪即采集首帧、边框变红，成片时间轴与音轨都从这一刻起算，初始化期间缓冲的声音丢弃。硬件编码器在后台创建，期间的画面与声音按原时间戳暂存（画面上限 256 MiB），就绪后补写。设置延迟开始时，初始化在倒计时期间完成，归零即开始录制；倒计时中取消会丢弃已预备的会话。原位预览在首帧解码前保持透明，不闪黑屏，声音随首帧画面一起开始。

GIF 录制与预览中的“转 GIF”共用自适应转换路径：短视频一次解码并缓存像素索引键；预计超出 64 MiB 缓存的视频复用解码器回到开头，直接生成 GIF 索引，避免写入大缓存。无法回到开头的来源兼容重新打开。保留整段全局调色板、相同帧合并与差异区域压缩，最多三个工作线程并行压缩并按原顺序写入。GIF 最多 15 fps、最长边 1280 像素。也可用 `raishot-cli --convert-gif input.mp4 --output result.gif [--gif-fps 15]` 直接转换视频文件；完成后输出实际策略和各阶段耗时 JSON。已有目标文件不会被覆盖。

远程桌面或远控软件中使用时，长截图与录屏的工具栏、边框、预览默认会从远端画面消失（它们不进入本机采集）。设置“截图 → 远程桌面 → 远程画面兼容”默认自动：远程桌面会话或框选时检测到远控注入输入，就全部改为可见并把边框画在选区外；只发现本机运行着远控软件时，不压选区的工具栏、面板和预览改为可见；仍看不到时选“始终兼容”。见[远程画面兼容](references/remote-display-2026-10-22.md)。

预览工具栏的历史按钮打开主界面历史页（独立进程，不占用录屏会话）；录屏目录顶层的成片与截图、贴图同列，可播放、复制文件、在文件夹中显示，删除时移到回收站。

### 2.8 截图历史

托盘“图库”、截图工具栏的历史按钮与录屏预览的历史按钮都打开主界面历史页：截图历史、贴图工作区记录（屏幕上、未打开、已关闭）和录屏成片按创建时间合成一条时间线，按本地日期分为今天、昨天、星期几和更早的月日，缩略图按原比例排成等高行。可按全部／截图／贴图／录屏筛选，搜索标题、类型、本地日期（2026-10-19、昨天）、尺寸和文件名。单击选中并在右侧详情栏查看时间、尺寸、大小、状态与分组；双击或 Enter：截图贴出、关闭或未打开的贴图恢复（含标注与撤销记录）、录屏内置播放。截图还可查看、复制图片、编辑、在文件夹中显示；录屏另有明确的“用系统应用打开”。Delete 删除后先从列表隐藏，底部可撤销（Ctrl+Z）10 秒，期满或关窗才真正删除；屏幕上的贴图需先关闭。方向键选择，Ctrl+F 搜索，F5 刷新，Esc 先清搜索再取消选择。贴出、恢复与编辑交给托盘启动，托盘的批量隐藏、关闭同样作用于这些贴图。

仅在设置开启历史后保存完成的合成 PNG，最多 50 张／256 MiB／30 天；未开启时历史页顶部提示并可一键开启，贴图与录屏照常显示。缩略图不另写磁盘，打开历史页时后台按时间顺序逐张解码。

录屏网格默认在后台读取首帧，文字贴图直接显示当前文字片段。历史扫描时自动清理已丢失全部图片、也不能从文字文档恢复的无效贴图记录；仍在使用或只是暂时读取失败的记录会保留。加载中与预览失败分别提示；文件大小或修改时间变化会使旧缩略图失效，F5／刷新按钮强制重读并重试先前失败项。

## 3. 截图界面快捷键

主路由：`src/capture_view.rs`（`CaptureView::key`）。按键依次经过：IME / 文字草稿 → 参数面板 → 工具栏临时菜单 → 全文输入器 → 自动复制失败恢复 → 原位文字层 → 只读识别结果输出 → 文件类快捷键 → 文字编辑 → 空格工具栏 → 预览光标微调 → 智能马赛克 → 取色 → 套索 → 通用动作表。前面的层消费后，后面的不再处理。

### 3.7 原位文字层（OCR 结果，`capture_ocr_overlay.rs` 的 `ocr_overlay_key`）

普通图片文件编辑也支持原位OCR：通过原有OCR入口识别当前图片选区，直接在图片上选字、复制、查找和使用四种标记；还可处理敏感文字、重识别整行及编辑全文。文字定位随图片缩放／平移和DPI投影，识别使用原图像素及实际选区，不读取预览棋盘格或界面浮层。复制文字成功后保持图片编辑器打开；失败保留正文、选择和历史。中键平移、打开／保存和全文输入法优先级保留。当前源码与64新模型／4直接旧模型已实际通过，真实窗口／输入法／剪贴板另待验，见[图片原位OCR阶段](references/image-editor-inline-ocr-2026-10-12.md)。

**右侧结果面板**（`capture_ocr_panel.rs`，布局见 `ocr_panel.rs`）：普通截图 OCR 时，面板停在选区右侧 12 DIP，宽 340；上沿对齐选区，下沿对齐选区下方的工具栏（不足 360 时向下延伸）。面板不与工具栏重叠：工具栏比选区宽而伸到面板位置时，依次改为止于工具栏上方、移到工具栏外侧、换到选区左侧；两侧都放不下贴显示器右缘，并缩到工具栏上方或移到其下方。识别中先在同位置显示骨架，完成后原位替换；面板打开时侧边完成栏让位。

- 标题栏：行数；查找（Ctrl+F，查找栏嵌在面板内）、编辑全文、更多（翻译所选／翻译全文、翻译图片 Y、重新识别全部、复制图片）、关闭（Esc）。

全屏截图和贴图共用 OCR 选字定位。ppocr 保留倾斜、垂直及 180°纠正后的裁行四角，拖选与四种标记沿原图中的阅读方向；段落复制对非水平或反向文本保留换行。词框仍为估算；ppocr在完整证据有效时以实际CTC发射区间的中心定位完整字素，再沿完整裁行在相邻字中心的中线切分，首尾贴到裁行两端：同一行的选区、命中和标记是一条等高的连续带，不按字间空隙或逐词墨迹高度拆碎。缺失、过期、多字素token歧义或预算超限时回退到原有有效文字框和词内估算，同样按整行连续切分，无需设置。

ppocr完成质量选择与重复行去重后，对具有可信原图像素证据的词投影保守收紧高度；正文、CTC宽度、字素中线停点、行投影及词／行归属保持。浅色、复杂背景、触边、标点／组合字素及证据不足仍用原框；这是标记高度改善；字素宽度在CTC证据有效时来自原始采样带，回退路线仍为词内估算。透明源按实际白底合成读像素，后处理不改原图片。

有完整行像素证据时，选字色带统一优化行高和首尾留白，已有内部字间分界保持。收紧后每侧以至少2原图像素或墨迹高12%为留白底线，行高不少于原框60%；原框已紧时不继续压缩。轻斜框只有在笔画更支持水平方向时才拉平，沿用同一留白标准。依据与实测见[OCR文字框与段落](references/ocr-boxes-and-paragraphs-2026-10-24.md)。

选中文字旁的工具栏统一使用复制图标、A高亮／U下划线／W波浪线／S删除线和黄红蓝绿四色点，操作名称在悬停提示中。两端普通浮条286×38 DIP；贴图窄窗口自动换成180×64两行，保持选区上下避让，清选、退出和黑色保留在识别菜单及原快捷键中。菜单和浮条使用同一色表。完整同类同色标记覆盖当前选择时，按钮显示活动底；混色、混类或部分覆盖不会误亮，再次点击取消该范围，撤销重做按实际文档恢复。全屏浮栏须完整放在显示器内并避开选字，没有空位时在OCR结果面板中保留图标与颜色入口，短面板的标题和底栏保持可用。标记快捷键仍为原H／U／W／D，S只是删除线的视觉符号。新的图标与回退样式已接入源码，实际界面及各自构建加载分别记录，见[迷你标记栏](references/ocr-compact-mark-tools-2026-10-11.md)。

浮栏现在同时避开截图侧实际OCR结果面板、可见主栏及属性栏；贴图侧避真正可见的标注工具栏位置，工具栏移动后通知浮栏重算。先寻找完整一行且位移最小的位置，无空位再使用窄区两行或原面板/菜单入口；不会硬夹回选中文字内或裁掉控件。12项相关后台布局模型通过，真实显示/点击及多屏DPI待自然使用；固定800图标包还不含这个避让后继，见[避让阶段](references/ocr-toolbar-avoidance-2026-10-12.md)。

标记按钮不可用时，悬停提示会说明需要完整文字定位和可用输入；复制文字不要求文字定位，仍须遵守当前输入状态。原图透明度、选区与套索裁剪、四种标记及PNG输出由[后台管线检查](references/ocr-mark-pipeline-2026-10-12.md)验证，实际悬停和剪贴板另待验。

其它按键在此层一律被吞掉，不落到绘图工具。

全屏原位结果面板的“表格”视图和全文结果操作行提供“复制表格”，仅复制完整识别矩阵为 TSV，成功后继续保留当前界面，失败可原地重试。编辑正文后旧表格定位失效，即使撤销恢复原字节也需重新识别；仅打开、收起未编辑的全文输入器保留表格。普通原文复制和图像输出保持。

全屏截图和贴图的有效 OCR 文字模式支持同一查找栏：按字面和完整字素匹配，保留大小写、组合字符、emoji 与原始换行。输入只显示当前命中的金色位置预览；“选中”才替换原文字选择并把焦点返回 OCR 层，随后 Ctrl+C 复制所选。缺少可见定位的命中仍可选择文字；查询字段有焦点时 Ctrl+C 复制字段中的文字。手动拖选或键盘扩选清除当前查找预览，保留关键词和命中列表。

查找栏的上一处／下一处／选中／整批标记在按下时绑定当前查询和文字来源，松开后的当前绘制才执行一次；按住期间换查询、换正文、换来源或失去焦点会撤销旧点击。忙碌或输入法合成期间修改查询，会在恢复操作后刷新缓存；旧回调不能执行旧动作。已接入源码，实际鼠标／输入法交互待验。

全屏和贴图的局部只读候选支持长按方向键／Home／End 连续导航或扩选，保留按词、字素和上下视觉行规则；复制、全选和取消只响应首次按下。相关模型通过，实际长按交互待验。

### 3.8 识别结果层（框选前 R / Shift+C 的结果）

录制绘图层拥有输入时另支持Ctrl+Z撤销、F9停止、F10暂停/继续。此层Esc先取消正在绘制的手势；没有手势时退出绘图，录像继续。工具栏的空格和预览输出键保持上表范围，不作为绘图层的全局快捷键。

调整预览音量后的另存先生成同目录自有暂存，编码完整收尾后才由当前保存意图提交目标。失败保留原文件和预览，提示重试；重录、换结果或再改音量会撤销旧保存，迟到任务只清已核明身份的暂存，不覆盖或删除最终目标。暂存被替换或失败／取消前尚未核明身份时保留文件，错误及诊断附实际路径。保存期间请求关闭会先等待提交，失败解除等待并保留预览。同源同目标也沿这条事务。分块混音原生媒体及相关文件事务检查已过，保存窗口交互仍未验。

普通MP4、GIF和混音的“复制文件”发布独立持久成品，随后关闭或重录保留已复制文件。新复制不覆盖现有目标；转GIF不借用未知同名文件。复制／保存成功只续接一次排队关闭，失败保留预览；旧任务不能清后继槽位。关闭回写使用当前自有原片和私有暂存，辅助轨道按文件身份清理，保留已另存到同一路径的新成品。原片保存后的已烘焙音量参与后续混音判断，恢复默认会重新从原音轨生成。上述安全接线已合入，后台模型与真实媒体的资格分别见[输出生命周期阶段](references/recording-output-lifecycle-2026-10-11.md)。

实验录前音量可分别调整或静音系统声与麦克风，录后预览继承本次录制值；再次调整会从原始分轨重混，保存覆盖原片后按实际成片继续判断是否需要重混。仅在 `RUSTSHOT_EXPERIMENTAL_MEDIA=1` 下开放录前选项，接线已编译并通过相关混音模型；真实录前控制与设备采集仍未验。

### 5.4 参数窗与保存面板

参数窗（`parameter_control.rs` 的 `key`、`finish_parameter_control.rs` 的 `key`）：Enter 应用、Esc 关闭、方向键 ±1、Home / End 到端点、Tab 切换焦点。保存面板质量滑块同理；Esc 关闭。

## 7. 已发现的适配问题（开发待办）

按影响排序，均已在代码中确认。

3. **贴图里 E、H 随工具栏状态改变含义。** 收起时 E = 文字选择 / H = 隐藏标注，显示时 E = 橡皮擦 / H = 荧光笔；用户看不到当前处于哪种模式。
4. **T / L / O 在截图和贴图中含义完全不同**（贴图 / 置顶，长截图 / 锁定，套索 / 重新 OCR）。从截图按 T 贴图后，再按 T 就变成取消置顶。
6. **框选前 P、C 与工具键冲突。** 有放大镜时 P 是坐标模式、C 是复制颜色；放大镜关闭时 C 复制 HEX，P 无作用。确认选区后 P 才是折线、C 无作用。
8. **Ctrl+0 / 0 不统一。** 图片编辑中 Ctrl+0 = 适应窗口、Ctrl+1 = 实际大小；贴图工具栏收起时 0 = 重置处理（与 1–8 图像处理同列）、Ctrl+0 = 100%、F = 适应；展开时数字属于工具栏。
10. **Esc 层级各窗口不同。** 截图 Esc 直接取消整个会话（丢弃标注）；贴图 Esc 先取消当前操作，无操作时直接关闭，工具栏展开不增加一层；长截图 Esc 关闭；录屏中 Esc 是停止而不是取消。
12. **无法自定义会话内快捷键**。全局入口已扩展到 13 项，OCR／翻译／复制等流程可通过快捷动作绑定；长截图与录屏的状态相关操作仍沿用会话内快捷键。
13. **键位依赖字母而非物理键位。** 匹配的是 GPUI 的 `keystroke.key`，非 US 键盘布局下 `[`、`]`、反引号等可能对应不上（尚未验证）。

改动建议（待决定）：抽出统一的快捷键表（按场景 → 动作），截图、贴图、提示文字和托盘说明都从同一张表读取，再考虑开放自定义。
