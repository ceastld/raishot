# DeepSeek API 识别与翻译实测

日期：2026-10-24（用户时区）。用户将本地模型保留为候选，本轮实际测试云API是否更适合轻量客户端。使用用户指定位置的已有凭据，仅运行时读取，没有复制密钥、修改配置或接入产品代码。

## 推荐

**优先接入DeepSeek Flash作为可配置的在线公式识别与翻译入口；表格继续保留现有本地默认，API列为增强候选。TexTeller/Index本地包保留作离线备选。**

理由：无需模型下载，本机测试客户端峰值工作集约67.4 MiB；公式与翻译完整耗时明显低于上轮质量优先的本地候选，费用很低。质量足以入围，但仍需公式预览和结构校验，不能把HTTP成功等同识别正确。

本轮正式78次调用，全部200、自然stop，无重试、超时、空输出或截断；请求还明确检查没有意外思考输出。正式轮次按usage估算约 **¥0.030747**，另一次单图冒烟约¥0.000360，合计约 **¥0.0311**。这些是token计价估算，不是账户账单回执。

## 已确认的质量问题

### 公式

- f19：把“样本均值”的下括号移到等式后单独的空白区域，原本与分式的关联丢失。数学等式还在，但不能算整式正确，需要用户修正。
- f18：原始字符串保留了裸中文“其中”，没有使用文字命令包装。统一XeLaTeX环境虽然exit0，日志实际报两个Missing character，PDF丢字。故原始内容正确，但当前可读排版失败。没有偷偷修原输出后计成功。
- 两例与本地TexTeller的暗色矩阵失败不同；这不是API在所有场景都胜出的证据。公式必须保留原图、源码、预览和编辑入口。

上述结论来自源图与原始 API 输出编译结果的人工对照；历史实验图未随仓库发布，不能用本页替代逐例复核。

### 翻译

- t24的原文为由真实Tab分隔的三个表头：“累计摊销／本期增加／期末余额”。译文词义正确，却改成竖线分隔，不能直接按原结构粘贴；按预注册标准算不可直接使用。
- 前轮的覆盖方向、mouse capture、下载完成数/总数等主要差错在API输出中表现更好。长段保留了unload的内存含义、代码、公式、URL和数值。
- s04把引号中的显示文案保留为英文，评为少量漏译3分；代码和实际Tab结构保持，仍可使用，不以单一参考措辞强行判错。

表格六图恢复的rowspan/colspan、多行、空格、前导零、负号、小数尾零、百分号均与真值一致。本轮没有重跑现有本地表格或做Excel/WPS真实粘贴，默认方案保持原样。

## 可复现的请求与连接条件

- 官方API，模型名deepseek-flash；当前官方表对应DeepSeek-V4.1-Flash-1017，回包模型名为deepseek-flash。[模型表](https://api-docs.deepseek.com/quick_start/pricing/)
- 明确thinking.type=disabled、temperature=0、stream=true、include_usage=true；没有工具或隐藏重试。DeepSeek默认会开启思考，现有通用enable_thinking模板参数不能代替它的专用开关。[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)
- 图片走inline PNG、detail=original；公式复用本地A/B共同白底/深色极性归一，保持尺寸；表格按预注册原样测试深色。只发送任务提示和图像，不发送LaTeX/HTML真值或评分答案。
- original仍受服务端内部图像处理，不等于数学上逐像素保留；本轮图片最大尺寸远低接口限制。[视觉API说明](https://api-docs.deepseek.com/guides/vision/)
- 翻译与本地轮使用相同保护提示、相同文本及目标语言，短段输出上限384、长段768；公式2048、表格8192，实际均自然stop。
- httpx持久Client、HTTP/1.1、并发1、显式沿用本机系统HTTPS代理；代理地址和认证信息不写入结果。首个新连接请求完整1.600秒，首字1.238秒，已在统计中保留。
- 正式轮次约109秒。没有并发/批量段落、全天拥堵、其它地域/网络、重试恢复、失效密钥、断网或长期压测，不能把本轮无失败当服务SLA。

## 接入时应补的内容

1. 在设置中提供服务、用户Key、模型和连接测试；首选deepseek-flash并关闭思考。现有纯文本翻译只有端点/模型等字段，还需补鉴权；图像识别还需多模态请求，不能仅更换端点就宣称已接好。
2. 公式增加无损中文文字包装/外围定界符规范化及真实预览检查；标签关联、矩阵等结构错误仍要能人工修改。
3. 表格结构保留在本机，翻译按稳定cell/paragraph ID处理文字，不让模型重写TSV；回包校验ID、占位符、代码和数字。
4. 使用连接池与流式反馈，翻译按段落合理打包；本轮没有测并发批量，暂不承诺整页瞬时完成。
5. 云模式需要联网，图片识别会发送选区图片，纯文本翻译发送文字；本地表格及可选离线包保留独立入口。测试Key没有写入产品或源码。

本轮只完成API实测和方案收敛，没有修改应用功能，没有构建项目、安装或发布。
